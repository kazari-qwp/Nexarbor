# 挂载 Agent
先选已有节点，再选择 Agent 预设或获准的自定义提示词，通过 datanet_agent_capabilities 查询可用预设和工具箱。
省略 preset 使用 worker；省略 toolboxes 使用所选预设默认工具箱，填写时选择该 Agent 的职责工具箱。框架仍附加默认委托和问题处理能力。prompt 提供完整自定义职责，需宿主允许。
max_signal_strength 是新 Agent 主动请求的最大访问预算，不超过创建者允许值；省略使用预设默认值。目标须在授予的管理范围内，普通写路径不是管理依据。
一个节点只挂一个 Agent，根节点已有原生 Agent。提示词为该实例独立保存，不与其他实例共用可修改文件。返回实际节点、会话和工具箱信息。
operator 是用于执行与验证的 Agent 预设，默认装配官方文件和本机终端工具，无需额外填写工具箱或官方运行预设；讨论角色用于小组，由网络预设统一装配。增加下属时同步更新上级职责、访问接口和工具需求。
