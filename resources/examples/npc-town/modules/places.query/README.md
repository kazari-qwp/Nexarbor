# 地点与处境查询

只提供查看处境、查询地点、查询地图三个按需工具。依赖本地 records.store / place.info，外部读取按 road_channels 查询道路与位置关系（默认 location/road），实际操作仍受模块授权限制。地图由可达地点道路生成 PNG，不含私人记忆或人格。

publish 是显式准备操作，按 public_fields 发布公开人物资料。角色执行配置可以在上下文准备前调用它。它不写四路输入，不扫描提示词，不承担角色的活动调度。map_title、map_layout 控制地图显示。当前时间由上下文组装器沿 tail 读取世界时间文本，处境查询不再重复读取或返回时间。
