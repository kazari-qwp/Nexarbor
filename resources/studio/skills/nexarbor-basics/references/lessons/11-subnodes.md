# 局部容器与归属

节点各自持有模块、工具、运行状态与真实出边；将节点分组或标明管理归属，不会把这些表并入父对象。

归属标记不是传播边，不分频道、不消耗跳数，也不授予同归属树内的无连线调用。需要管理或业务调用时，配置真实连接和相应频道；模块仍通过 access 到达对方。

上下文组装器和工具发现器可以装在 Agent 本节点；普通上下文只读取 markdown 数据节点，工具发现跳过其他 Agent 的工具与发现器。需要独立出边时用显式节点和连接表达，不依赖 use_parent_links/share_links 的隐式视图。

复制节点或网络时保留其独立数据与表，按声明的节点引用重映射；复制本身不检查或补装模块依赖。归属展示与业务可达范围分别核对。
