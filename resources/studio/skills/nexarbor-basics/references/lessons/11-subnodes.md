# 模块的亚节点展示

亚节点只是一种前端模块卡片，不是网络中的节点。模块可用 frontend.display_as="subnode" 声明卡片，并用 frontend.channel_groups 指定配置中的频道组；未声明分组时使用模块的访问频道。画布仅显示比普通节点小的名称矩形，频道见悬停提示与模块配置。上下文组装器沿用这种展示。

模块仍装在宿主节点上，状态、工具、出边和锁仍属于宿主。卡片不分配独立的运行 ID，不增加访问权限；从卡片建立的连接保存为宿主的真实连接。业务调用仍通过 access 和真实频道。

上下文组装器和工具发现器可以装在 Agent 本节点；普通上下文只读取 markdown 数据节点，工具发现跳过其他 Agent 的工具与发现器。需要独立运行状态或出边时，用显式节点和连接表达。

复制节点或网络时复制其数据和表，按声明的节点引用重映射；复制本身不检查或补装模块依赖。卡片由复制后的模块声明生成。
