# 保存、版本与副本

完整网络保存结构、装配配置、状态与可携带文件；项目 Commit 使用真实 Git 保存受管理资源与 Agent 会话位置。正文在项目内的文本参与版本，明确关联的外部文件不由项目 Git 管理。

配置、当前运行状态、文档正文与 Agent 会话上下文是不同材料。组件的 config_schema 默认值不能当作已经发生的状态；网络视图来自固定快照，不能与其他轮的状态混用。恢复日志位置也不表示重新执行过副作用。

复制 Agent 的配置不带原对话上下文。复制文本和数据要生成独立存储，不能只换节点 ID 而共用同一个文档。保存完整网络和导入可携带上下文位置；中途改变输入后继续运行可以分叉历史。

复制网络时新分配节点 ID，内部的显式引用映射到新副本；保留外部联系的模式才继续引用原外部节点。模块参数中的节点引用须按 Schema 声明 node-id，普通字符串不应被猜测成节点 ID。

事务回滚保护一次局部修改的中间状态，Git 保留项目版本，模型会话分支保留历史；三者不能互相替代。判断是否保存或恢复成功，需要实际提交、日志或状态证据，不能仅凭一个配置项存在。
