# 工具权限

工具首次开放时注册定义。停用时保留本轮声明系列中的定义，框架立即关闭该 Agent 的执行权限；恢复时重新开放权限。停用、恢复通知以普通历史消息追加在下一次模型请求的尾部。

临时排障工具在问题通道结束后停用。单次回复工具在回复完成、消息过期或丢弃后停用。官方工具的权限调整也保留本轮声明系列中曾开放的定义，通过执行拦截控制当前授权。

压缩成功后，按当前授权和保留历史中的工具调用重建声明清单。已停用且不再被保留历史引用的动态工具注销定义；官方工具清理曾开放记录和作用域白名单。部分压缩留下的旧调用仍保留对应声明，但不恢复执行权限。压缩失败不触发这项清理，仍有效的工具保持可用。

自动压缩可能发生在请求装配之后；AgentLoop 在发现 surface replacement 时重新装配，紧接着的请求及溢出重试使用新清单，不再多携带一轮已清理定义。当前仍使用 addition-only，不向拒绝 tool_removal 的服务端发送原生移除事件。

停用工具的调用返回 `DATANET_TOOL_PERMISSION_DENIED`，工具本体不执行。已回收定义的工具也可能由原生工具注册表返回不存在；两者都不会运行旧工具。调用仍记录在工具报告中，权限拒绝不作为故障证据，也不计入排障验证。真实工具故障继续按原流程记录。

权限和清理按 Agent 独立维护。压缩不撤销有效授权，也不授予新权限。重新开放已回收工具时重新注册当前定义；旧释放回调不能停用新注册。同名动态定义在没有保留旧调用的压缩边界更新。销毁或重新挂载 Agent 时按现有授权重新建立工具；恢复日志不会自动重新授权历史工具。
