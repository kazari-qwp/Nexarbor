# 工具权限

工具首次开放时注册定义。停用时保留定义，框架关闭该 Agent 的执行权限；恢复时重新开放权限，不重复注册定义。停用、恢复通知以普通历史消息追加在下一次模型请求的尾部。

临时排障工具在问题通道结束后停用。单次回复工具在回复完成、消息过期或丢弃后停用。官方工具的权限调整保留曾开放的工具定义，通过执行拦截控制当前授权。

停用工具的调用返回 `DATANET_TOOL_PERMISSION_DENIED`，工具本体不执行。调用仍记录在工具报告中，权限拒绝不作为故障证据，也不计入排障验证。真实工具故障继续按原流程记录。

权限按 Agent 独立维护。首次开放仍按原来的通道条件执行；创建节点不增加参数。定义在该 Agent 的存活期间保留，压缩不撤销权限状态。销毁或重新挂载 Agent 时按现有授权重新建立工具。
