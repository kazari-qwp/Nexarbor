# 操作说明加载

通道指南、网络预设说明、报告指南、排障指南、恢复次数说明和已选用的 Skill 正文，以独立历史消息进入上下文，不加入系统提示词。

进入对应通道时，正文尚未加载或已经被压缩掉，就加载一次；正文仍在当前历史中则不重复加载。压缩后不主动恢复文档，保留区域内的正文也不重复加载。摘要中的相关知识不视为完整正文。失败压缩不清除加载状态，各 Agent 独立管理。

文档加载和工具授权分别管理。压缩不撤销已开放的工具；问题通道结束时关闭其临时工具的执行权限。首次真实 datanet_feedback 开放修复工具并加载指南，后续可通过修复通道重新查看已被压缩的指南。报告工具也遵循同样的文档周期。

Skill 授予的能力可以恢复到新会话，但正文在再次 load/read 时才加载。角色职责、权限和当前运行状态继续由各自机制提供。文档不作为权限来源。

工具首次开放由 Harness 的 addition-only 路由添加定义。停用时保留定义，由框架关闭执行权限；恢复时重新开放权限，状态通知追加到历史尾部。当前公共 API 和客户端账户路线均拒绝 tool_removal，运行配置保持 addition-only。具体见 [工具权限](TOOL_PERMISSIONS.md)。
