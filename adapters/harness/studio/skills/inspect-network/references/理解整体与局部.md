# 理解整体与局部

`view_network` 每次返回新图、稳定的 N/E 编号、计数和有效筛选。默认折叠亚节点，只保留参与执行的文本；图片包含全部匹配节点，文字索引最多24项。大图的 R 框用于请求局部原图，不要求逐框遍历。

查看磁盘项目时先用 `view_network(project="项目文件夹的绝对路径")`。同一轮后续节点、边、模块、源码和文本查询沿用该项目；换项目重新指定 project。外部文件变化用 refresh:true 重新读取。当前工作流用 source 切回，不同时传 project 与 source。

下面是独立示例，不是必须依次执行的流程：

```json
{"include_text":false,"include_subnodes":false}
{"exclude_types":["agent"],"relations":["road"]}
{"channels":["tick"],"show_channels":true}
{"selected":true,"hops":1,"include_subnodes":true}
{"nodes":["N3"],"hops":2,"direction":"out"}
```

先从总览的 `available_channels` / `available_relations` 或准确边查询发现实际名称，不把示例中的 road/tick 当成所有网络都有的约定。

## 连续调整

假如上图返回 `view:"V0123456789abcdef"`：

```json
{"view":"V0123456789abcdef","exclude_types":["agent"],"include_text":false}
{"view":"V0123456789abcdef","reset":["channels","nodes"],"relations":["road"]}
```

未提供的筛选继承，提供的列表替换原列表，`[]` 清空列表；`reset` 恢复指定项的默认行为。省略 view 从默认视图重新开始。隐藏全部文本用 `include_text:false`，显示全部用 true，重置后只保留活动文本。排除优先于保留；各类条件之间取交集，模块保留列表内部是任一匹配。名称 query 是子串，不支持自然语言或正则。

`exclude_nodes` / `exclude_types` / `exclude_modules` 隐藏节点，`relations` / `exclude_relations` 过滤边。边的任一端被隐藏时不绘制该边，也不会自动补一条跨越隐藏节点的连接。`hops` 沿筛选后的边扩展，方向由 direction 决定；这是结构邻域，不是运行权限模拟。

空结果先检查有效 filters，可 reset 或重新取无筛选图，不要据此宣称网络为空。

排查信号时通常保留默认的活动文本；文本节点也可以装时钟或执行模块。若隐藏文本后出现 boundary_edges，重置 include_text 或核对边界节点，不能把被隐藏的执行中继当成不存在。

## 放大与输出

`{"view":"V0123456789abcdef","region":"R2"}` 放大原区域，保持原布局和编号；可加 show_edge_ids/show_channels 标注。区域请求不能同时改变筛选；改筛选就省略 region，新图可能重新排布。

图片不可用或模型不支持图片时用 `image:false`，按返回页数翻页。视图只在当前进程缓存，最多保留最近24个；失效后重新取图。图片不是执行录像。
