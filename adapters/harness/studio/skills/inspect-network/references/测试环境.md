# 用户表达效果，制作 Agent 设计方案

用户可以说“让当前商店支持赊账”或“让讨论成员投票”，不必预先提供模块设计。先查看当前网络，找出目标节点、已有记录与接口，再搜索可复用能力。用配置解决差异；缺少的能力才做成通用组件。模块 Agent 产出组件包和装配说明，网络 Agent 产出网络配置。

## 按需理解网络

有网络观察能力时，使用会话中的 `inspect-network`（查看网络）Skill。它按问题提供图片筛选、节点模块表、连接与源码查询；复杂用法只在需要时读参考，不必先导出全网 JSON。

网络制作默认 `source="candidate"`；全局制作 Agent 可直接观察 `current`，`environment` 是已 reset 的独立副本。局部管理员的来源仍是可达性裁剪的网络。也可用 project 查看任意磁盘项目，但它不属于 test_environment 的 source，不能把只读查看当作试运行。观察只读，不代替测试；修改副本后重新获取快照，不混用旧图。

制作 Skill 提供 test_environment 工具：

1. `action=reset, source=current` 复制当前网络、模块状态和受管理文本；网络制作也能 `source=candidate` 测试 network.json。
2. reset 返回副本概况；用查看工具 source=environment 按需观察节点、模块或连接，不先索取全部配置。`inspect,node=目标ID` 可显式取得该节点的挂载配置和状态。
3. `action=mount, node=目标ID` 试装当前组件，填写 config/state/access；module 可选择已发布依赖。只改变测试副本。
4. `action=call, actor=发起者ID, node=目标ID, module=模块ID, operation=操作名, arguments={}, strength=2, channels=[...]` 检验真实路由、锁与状态。参数 ID 仍不授予权限。
5. `action=inspect` 查看测试后的副本；`action=signal` 以 actor 为信号源，使用 channels/strength/arguments 作为传播参数与内容。

源码改变后必须 reset，新副本使用新源码，旧副本保留用于审阅。测试禁用真实模型、外部副作用和节点工具箱；隔离项目内的 runtime:read_text、已登记模板的 templates:instantiate、runtime:checkpoint 可真实运行。检查点只保存测试副本；恢复验证仍需实际关闭重开。文件路径改到测试目录，原生日志位置和执行绑定被清空。这是业务测试隔离，不是 Python/操作系统安全沙箱；禁止通过代码绕开 ctx 或访问测试目录外的资源。

网络 Agent 可调用 copy_current_network，把当前网络复制为 network.json 草稿，再按需求调整；草稿保留成品执行配置，清空原生日志位置和正在运行的信号。测试执行仍使用禁用副作用的独立副本。

正确：先核对商店账户接口 → 试装通用额度组件 → 测正常购买、余额不足、并发与断边 → 报告测试结果和建议挂载。
反例：要求用户先给出函数方案；猜测全局变量；在正式网络试写；看到外部工具被禁用就自己启动终端绕过。

网络结构与状态副本能验证具体流程，但真实模型选择和真实外部副作用需要另外的明确运行验收。测试通过不自动修改或替换正式网络。

网络制作可在 `tests/test_*.py` 写自动行为测试，使用 `datanet.studio.network_testing.NetworkHarness` 重跑候选。`validate` 会实际收集并执行，覆盖真实路由、信号、状态、输入包消费与存档恢复。用法按需读 make-network 的 `references/行为测试.md`；不要以静态校验代替运行验收。

本地模块携带的工具仍可测试：调用自己的tools.collector.collect查看origin列表。禁用的是外部工具执行及节点工具箱，不是组件公开操作；不能把“不能调用真实外部工具”误解为无需检查模块工具收齐。

操作默认只返回业务结果和概况，不重复整个节点表；很长的业务值也先给结构摘要，signal 返回传播摘要与少量失败节点。完整操作结果用 test_environment(action="inspect",section="result",start_line=1,line_count=120) 按行读取。缺少的项目模块保持缺少，不从框架同名模块回退；源码改变后 reset 会装入当前候选。
