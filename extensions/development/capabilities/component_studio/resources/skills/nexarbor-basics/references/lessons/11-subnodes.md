# 亚节点与局部容器

亚节点可以挂在普通节点或另一亚节点下，允许独立未挂接状态，归属不能成环。它没有本地数据存储和散度，但有独立模块、工具、运行状态、授权与真实出边表；父节点的模块表和工具表不包含这些条目。

归属虚线由编辑器绘制，不是实际传播边，不分频道、不消耗跳数。相同归属树内的模块可通过 ctx.local.call 本地调用；模块的参数、状态隔离和自身授权仍然有效。跨归属树的业务访问仍按正常路径检查。

两个开关默认关闭：

- use_parent_links：子容器使用直接父对象的有效出边。
- share_links：把自己的出边及明确共享的后代出边开放给直接父对象。

这些表分开存储，核心构造有效读取视图并去重；不是在一张表里由模块过滤。嵌套共享逐层生效，不能越过中间层。模块作者调用 ctx，不重写共享或检索机制。

Agent 可在 execution.prepare 引用上下文组装器所在亚节点，工具来源在 execution.tool_sources 显式列出。父节点没有某模块不等于整个归属树不存在它；看亚节点自己的装配表与开关再解释。

复制父节点带上后代并映射归属和显式节点引用；单独保存亚节点解除原归属，拖到新父对象可重新挂接。模块自身的数据仍按独立实例处理。
