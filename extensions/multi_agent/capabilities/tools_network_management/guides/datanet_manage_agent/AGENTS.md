# 管理 Agent
通过管理归属操作获准节点，不借用目标 Agent 的私有工具或 Skill。
inspect 查看当前状态、提示词和工具箱。update_prompt 使用完整提示词替换并保存，保留已有上下文；补充职责时保留仍适用的原要求。
restart 和 clear_context 在当前实现中都重建普通 Agent 会话，因此已有对话上下文不保留；使用已保存提示词，或采用本次提供的 prompt。已加载的能力 Skill 重新装配。
目标忙碌时不修改。讨论成员仅支持 inspect/update_prompt，重启与上下文生命周期由讨论调度管理。
此工具不支持修改工具箱；真实报错后的补工具使用管理者修复通道。提示词变化不能代替能力授权。
