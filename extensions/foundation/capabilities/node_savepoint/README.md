# 信号计数存档点

在任意普通节点显式装配 `checkpoint.counter`，复用 `signal_response` 接收配置频道的信号。无 Agent 工具、无场景依赖。

```json
{"checkpoint.counter":{"config":{"channels":["world.tick"],"interval":5},"state":{"count":0}}}
```

每次到达后计数，达到 interval 的整数倍调用核心 `save(full=true)`。同一信号在广度优先汇入时只处理一次；重复最近信号不会重复计数。计数和最近信号随节点持久化，卸载模块即解除响应。

核心立即持久化全量状态和待发布标记。执行器适配层在工具结果全部落盘、日志位置与核心版本一致后，发布全量恢复点；否则保留标记等待下个安全点。上下文仍由原生 append-only 日志及位置引用保存，不复制整份日志。中途崩溃不会丢失该请求。

用于小世界的连接是 `脉冲 → 时间文本 → NPC → 存档点 → 脉冲`。该模块不推进时间、不运行居民，也不执行任何业务结算。
