# 可达工具装配器

Agent 节点挂载 `tools.assembly`。主机调用 assemble(context)，从自身连接发现按工具声明频道可达的公开工具，形成已绑定目标的动态入口。单独装配不启动模型。

```json
{"strength":2,"filters":{"move_here":{"hops":[2]}}}
```

强度不能超过会话授权；默认不包含自身工具。filters 是按原工具名的可选路径跳数筛选，小世界通过配置只呈现邻居地址的移动入口。模块实现不认识地图或 NPC。

别名格式为 near_<原工具名截断>_<定义与目标哈希>；描述为 <节点名称>：<原描述>。目标、访问频道、参数定义或名称变化会得到不同入口，防止复用旧定义。多个同名服务不会冲突。

调用无需先做模型侧 node_tools 查询，但仍在同一事务锁内重新验证当前路径、强度、工具声明的频道、目标启用状态、公开性与完整定义，再复用核心 invoke_tool。旧入口不能扩大权限。成功后发出 node/tool-invoked 事件，应用可在事务外正常结束轮次。移除的动态入口经现有 Harness 权限机制停用；原生 addition-only 工具声明可能保留在历史中，但不能继续调用。

装配器不负责启动 Agent、收集人物信息或响应世界信号。卸载删除自己的动态入口。
