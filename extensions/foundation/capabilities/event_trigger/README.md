# 事件触发器

匹配事件，选择要启动的执行图。

节点模块 `event.trigger` 按 type、频道交集及 JSON Pointer 等值条件匹配事件，把选中的图交给模块执行器。操作表固定引用同一节点已装配的模块方法；事件内容不能增加权限或选择任意 Python 函数。

支持核心信号、普通同步应用事件，以及 await Application.emit_async 的异步事件。普通应用事件由事件发布方在事务成功后发出，不自动监听任意业务内部状态。完整执行图返回后，信号才能传播到下一层。

配置、接口、恢复与限制见 [执行图接口](../../../../docs/EVENT_EXECUTION.md)。
