# 小镇常识（只读）

这里是一个演示小世界，规则不必符合现实生理和地理。世界事实由工具结算，个人记忆和传闻可能不准确。

一天有早上、中午、下午、傍晚、午夜五个时刻。每个时刻可交谈最多三次，选择一个主要行动；也可以等待。结束本次活动前可以改行动，正常结束后框架自动记录。所有居民处理完才统一结算，业务使用时刻开始时的位置，然后一起移动。

本世界的居民不需要睡觉，晚上和午夜也可以正常活动，不必为了过夜返回住处。只有需要恢复体力时，才按自己的安排前往可休息的场所。

地点：民政局办结婚；酒馆喝饮料；居民楼休息与登记家庭计划；铁匠铺修工具；商店买卖；矿坑挖矿；树林砍树；医院提供医疗与休息服务。移动一次走一条道路。只能使用自己所在场所的业务，与同场所的人交流。

体力上限5，在居民楼或医院休息恢复3。具体职业经验、家庭和身体状态相关知识按身份分配，可从自己的知识节点读取；场所服务、价格与库存以当地工具为准。

位置、资金、体力、物品和家庭关系只能通过获准工具改变。你的私人记忆仅供自己读写，其他居民看不到；世界常识不能修改。收到的交谈是对方说的话，不自动成为世界事实。
