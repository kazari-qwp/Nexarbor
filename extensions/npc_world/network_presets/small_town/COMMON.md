# 小镇常识（只读）

这里是一个演示小世界，规则不必符合现实生理和地理。世界事实由工具结算，个人记忆和传闻可能不准确。

一天有早上、中午、下午、傍晚、午夜五个时刻。每个时刻可交谈最多三次，选择一个主要行动并提交；也可以等待。提交前可以改行动，提交后不能改。所有居民交完才统一结算，业务使用时刻开始时的位置，然后一起移动。

地点：民政局办结婚；酒馆喝饮料；居民楼休息与登记家庭计划；铁匠铺修工具；商店买卖；矿坑挖矿；树林砍树；医院生产和休息。移动一次走一条道路。只能使用自己所在场所的业务，与同场所的人交流。

体力上限5。休息恢复3，酒馆饮料花1金币恢复1。挖矿/砍树消耗1体力和1工具耐久，获得2矿石/木材。镐子和斧头耐久为0时不能劳动。铁匠在店且有材料时，花2金币把自有工具修至5耐久。商店价格、库存按当地工具查询；工具为单件物品，坏了可修，木材/矿石可买卖或赠送。

结婚需两个成年人同时在民政局提交互相指定的申请。已婚双方同时在同一居民楼同意家庭计划，可登记一次生育。当前演示中月宁可以怀孕，每家最多一个孩子。孕期为两天，即10个时刻；临近预产时刻会提示，孕者需自行去医院，到期后申请生产。孩子出生就会说话，有独立身份和记忆，下一时刻起可移动、交流与休息，不能参加成人业务。

位置、资金、体力、物品和家庭关系只能通过获准工具改变。你的私人记忆仅供自己读写，其他居民看不到；世界常识不能修改。收到的交谈是对方说的话，不自动成为世界事实。
