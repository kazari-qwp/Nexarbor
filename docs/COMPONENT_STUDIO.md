# 客户端组件工作室

当前使用 `nexarbor-module/v3` 固定异步入口，网络配置为 v8。未指定路径时使用 `build/workbench-v3`；本机桌面快捷方式已绑定独立的 `build/studio/workbench-v3`。旧小镇、旧应用、旧发布组件和旧测试预设尚未迁移，未添加兼容层。

1. 打开 Nexarbor 桌面工作台。节点“工具”页可从本机 Harness 官方目录添加工具，设置提供频道；应用网络后生效。
2. Agent 属性中启用 Harness 执行器，设置 strength 和 channels。Agent 沿连接调用 `network_visit`，取得可达节点提供的工具；每次执行会重新检查权限。
3. 打开“组件工作室”，选择“从空白制作组件”或“标准 v3 组件”。使用 CodeMirror 查看、编辑源码和差异。
4. 连接已运行的 Harness 后，可将需求交给组件制作 Agent；它使用原生会话和编码工具，会话可在 Harness 列表中查看。也可以手工修改组件。
5. 验证在独立 Python 子进程运行，有时间和输出上限；校验清单、固定入口、挂载、信号响应、状态和组件自带测试。
6. 通过后才可发布，发布内容必须与已通过验证的源码摘要一致。修改代码后必须重新验证。发布版本只读，可以建立修改副本。
7. 选择节点并装配。示例的 state/access 会保留；主界面的模块页可以查看配置、网络访问授权和状态。组件之间通过公开操作复用，不拿其他实例引用。

制作会话支持继续或分叉历史；指南前缀变化时应开新会话。固定入口和本地 API 见 [组件说明](LOCAL_MODULES.md) 与 [制作指南](../extensions/development/capabilities/component_studio/resources/MODULE_GUIDE.md)。

制作 Agent 的职责、核心 API 和页面协议统一使用中文说明，保留代码标识和协议字段。每次开始制作时工作副本刷新三份当前规范；规范或依赖接口变更后，旧历史不能继续或分叉。测试文件必须由 unittest 实际收集运行，零项收集不会被当成业务验证通过。

## 组件源码和制作资料

“组件文件”只显示组件自身的 Python、清单、示例、测试、说明和页面。宿主的 `AGENTS.md`、制作规范和依赖参考在“制作资料”中只读显示，不混在新组件源码列表内；制作 Agent 仍可直接读取这些文件。目录按层级折叠，行内只显示文件名。

工作副本右侧垃圾桶用于删除工作副本，编辑区“删除文件”用于删除当前可选文件，都会先确认并归档到当前工作区的 `studio/trash`。已发布组件不随工作副本删除；`module.py`、`module.json`、`example.json` 和制作资料受到保护。运行中的制作／验证任务和过期的编辑内容会阻止删除。

## 连接、书签与快捷键

选中节点后，“属性”或“连接”页的“新增连接”按钮打开方向、频道、门槛和倍率设置。“连接”页列出本节点出边与入边，出边可删除；默认右键从一个节点拖到另一个节点也能打开连线设置。

默认操作如下；左上角“设置”菜单悬停或点击展开后，选择“自定义快捷键”，可以修改这些键盘及鼠标组合，并保存到当前工作区。文本框和源码编辑器保留文本编辑的撤销行为。

| 操作 | 默认快捷键 |
| --- | --- |
| 复制内部子网／保留外联子网 | A／B |
| 删除悬停书签 | A 或 B，可单独指定 |
| 保存网络草稿／删除选中元素 | Ctrl+S／Delete |
| 撤销／重做 | Ctrl+Z／Ctrl+Y |
| 累加或取消点选节点、边 | Shift+点击 |
| 扩大／缩小选区 | Shift+滚轮向上／向下 |
| 节点间拖动连线 | 右键拖动 |
| 重命名悬停书签 | 中键 |

撤销／重做只记录网络和布局修改。书签新增、删除、重命名、分类和选区变化不进入撤销队列，也不清空已有重做记录；拖入书签生成网络仍然可以撤销。鼠标停在书签卡片位置连续按删除键，会依次删除该位置补位后的书签，无需移走再移回来。

选区按“节点—边—节点”每次扩缩一层。A 复制选中节点并只保留内部出边，B 保留所有出边。仅选边时，两种模式都不保存起点；A 只保留边参数，B 额外保留终点。纯边书签拖到节点上将该节点作为新起点，缺失端点时由连接弹窗补齐。

书签拖入画布会创建新编号的副本，内部链接指向新节点；B 的外部链接指向仍存在的原节点。副本使用独立的文档目录，不复用原生 Agent 会话。两种背景色区分模式，复杂子网显示缩略图，名称仅悬停显示。相同选区连续按同一复制键两次取消刚建的书签；A、B 各按一次分别建立两份书签。

书签支持 A 子网、B 子网、单点、纯边四类筛选；新建书签进入当前自定义分类。书签区和历史区宽度约为 3:1，默认使用 48×40 的纯图卡片：单点为小圆圈、纯边为线段、网络为缩略图，悬停只提示名称。书签区右上角按钮同时切换两区的纯图／原文字视图；纯图按可用空间分页，文字视图每页 6 项。

历史区保留最近 100 个实际创建或使用的节点、边、书签，可定位、悬停按复制键复用，也能直接拖入画布。拖入历史节点使用当前节点的副本，原节点已删除时使用保存的副本；历史边保留终点，新起点由落点决定；历史书签保留保存的复制方式，书签本身删除后仍可从历史恢复副本。添加、删除、重命名书签或切换视图不改变历史顺序。书签、历史、分类、视图和左侧栏折叠状态保存在当前工作区的 `editor-library.json`；画布修改需保存草稿，点击“应用网络”才改变运行网络。

文档、组件、导入导出、保存应用、视角切换及布局按钮统一放在紧凑的单行顶栏。窗口较窄时，布局操作区支持横向滚动。左右侧栏的标题旁有折叠箭头，收起后保留 32 像素展开栏。右侧工作区在没有选中节点和边时自动收起，选中后展开；手动折叠／展开只覆盖当前选择，改变选择后恢复自动规则。仅剩根节点时仍正常显示节点。

节点保持圆形，悬停时不再出现方形预览。名称下方在悬停或选中时显示两组小按钮：工具图标加当前提供工具数、模块图标加已装模块数。每组图标与数字属于同一个按钮，点击任一部分直接选中该节点并打开右侧“工具”或“模块”页，不触发 Agent 对话或改变节点位置。

运行控制固定在左侧栏底部，分成两行：第一行是进度状态和脉冲选择，第二行是单步、运行／暂停、时刻数。上方组件和筛选内容单独滚动；收起左侧栏时一起隐藏，展开后恢复。画布和右侧工作区一直延伸到状态栏上方，不再为运行区占用整行底部空间。

## 模块自己的配置页面

组件可在清单中声明 `"frontend":{"entry":"ui.html","title":"元数据字段","height":460}`。页面作为组件源码的一部分验证、发布、导出，修改后必须重新验证。当前使用自包含 HTML，脚本和样式放在页面内；没有页面的组件继续使用 JSON Schema 通用表单。

选择节点，进入“模块”，展开模块即可使用它的页面，也可切换到通用表单。页面通过 `NexarborModule` 获得本模块配置和状态的副本，提交的新配置经过 Schema 校验后进入网络草稿，点击“应用网络”生效。它不能调用任意后端 RPC、修改网络授权或读取其他模块。iframe 使用独立来源沙箱，宿主令牌不会交给页面。

组件工作室支持编辑 `.html/.css/.js`，并提供“页面预览”；发布版本仍只读。详细接口和中文界面要求见 [页面开发规范](../extensions/development/capabilities/component_studio/resources/FRONTEND_GUIDE.md)。

开发组件库附带由真实制作 Agent 编写的 [metadata.fields](../extensions/module_frontend_demo/capabilities/metadata_fields/README.md)：点击“＋ 添加元数据”增加名称、类型和值，支持删除字段，以及字符串、数字、布尔、对象、数组和空值。字段在 `read` 操作或 `metadata.refresh` 信号执行时发布到本节点的模块元数据命名空间。Python 与 HTML 均原样导出，来源摘要见组件内 `provenance.json`。

## 本机 Harness 安装路径

工作室优先使用 `DATANET_HARNESS_EXE` 环境变量；其次读取项目本地、未入库的 `build/harness-installation.json`，格式为 `{"executable":"E:/dsh/Harness/DeepSeek Harness.exe"}`；都没有时采用 Windows 默认安装目录。SDK 从所选程序自身的安装目录加载，避免新版程序混用旧 SDK。测试客户端使用独立 `DSH_HOME` 和界面数据目录，临时文件保存在项目的 E 盘 build 下，不改日常客户端或全局 TEMP/TMP。

“整理当前视图”只根据当前可见节点和连线整理布局；“整理选中”用于选定部分。筛选和普通拖动不会自动触发全图整理。

## 工具、模块资源栏与配置书签

左侧“工具栏”“模块栏”默认折叠。展开后按资源管理器方式浏览：顶部是返回、前进、上一级和可点击的面包屑路径，下面只显示当前文件夹的下一层文件夹和资源。双击文件夹进入，单击资源打开右侧详情。右键菜单支持新建文件夹、重命名、剪切、粘贴；默认快捷键为 Ctrl+Shift+N、F2、Ctrl+X、Ctrl+V，可在设置中修改。目录层级、资源别名只保存在当前工作区的 `editor-library.json`，不移动源码或工具文件。

资源栏中的模块未挂载到节点时也能使用自己的配置页面，或者 JSON Schema 通用表单。填写后点击“Save · 保存至书签”，保存模块引用、配置、默认状态与访问授权；工具保存引用和提供频道。保存到当前书签分类，不执行组件，不改变当前网络。点击已有资源书签可继续编辑并保存同一书签。已挂载模块和工具的条目顶部也提供保存至书签、垃圾桶两个图标；垃圾桶只从当前节点卸载，不删除资源文件。模块书签保存当前配置与授权，新实例使用默认状态；覆盖已挂载模块时保留该节点的运行状态。

从资源栏、书签或历史拖工具／模块到节点，装配进入网络草稿，可撤销；点击“应用网络”才影响运行网络。重复装配相同工具引用时更新频道，不重复添加。实际装配才记录使用历史；保存、重命名、整理资源目录不改变历史顺序，也不进入网络撤销队列。

书签与历史均可筛选单节点、单边、网络、工具、模块；书签还保留 A/B 复制筛选。工具采用蓝色背景、模块采用金色背景，悬停显示“名称：描述”，中键可重命名。模块可在清单顶层提供可选的 `preview` 自包含图片，书签和历史有图显示图片，无图或图片失效显示名称。具体格式见 [页面开发规范](../extensions/development/capabilities/component_studio/resources/FRONTEND_GUIDE.md)。预览图只从当前模块目录读取展示信息，不为每条历史重复存储图片。

左右侧栏与画布相邻的边缘可拖动调整宽度，宽度按工作区持久化；保留折叠功能，窗口变窄时为画布保留空间。最大化、还原及窗口缩放会同步缩放画布视口，保留查看中心及节点坐标，不触发重新布局。小地图内外尺寸一致，固定在画布右下角，随可见图和视口更新。

外部工具与节点组件分开。当前适配的是官方文件、搜索、PowerShell 和后台任务服务，共十个工具；目录和工具测试不需要模型密钥。真实 Agent 对话与组件制作仍使用用户连接的 Harness。通用 MCP/Skill 导入和旧应用迁移以后处理。

验证子进程和模块接口边界不等于恶意代码沙箱。组件源码按可信本地代码运行，外部工具按宿主权限执行。

本轮实际桌面测试已走通：选择官方工具、应用、访问取得、调用读取、断开后拒绝、v3 模块验证／发布／挂载，以及重启恢复。没有付费模型调用。旧小镇的历史测试记录继续保留，但不代表它已在当前协议下复测。
