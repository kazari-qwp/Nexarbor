# 制作 Agent 与当前协议应用验收

2026-10-19。本轮完成模块／工具统一制作器、网络预设制作器、当前网络副本测试和配置复用工作流，重建 NPC 小镇，并用固定协作组、知识归档和新需求盲测验证。所有运行数据与模型日志位于 E 盘。

## 制作能力

| 输入需求 | 实际结果 | 新会话步骤 |
|---|---|---:|
| 同办公室私人便条，发送扣费，不让隔壁偷看 | 复用消息组件，输出配置书签；独立复测收费、幂等与权限 | 30 |
| 免费公开留言，最近50条 | 从上一输入回答前的种子分叉，复用另一配置 | 21 |
| 目前商店借还金币、最多欠8枚、原买卖保留 | 查看真实小镇副本，复用业务服务，输出配置书签；独立验证借还、上限、超额还款、原交易、书签装配与授权保留 | 35 |
| 新的两人读书组 | 不读取其他网络答案，从接口和教程组装；验证资料、消息、私人记忆与工具收集 | 41 |
| 单人资料助理 | 从上一需求回答前分叉，重新组装并验证归档恢复 | 34 |
| 需要最近N个数的统计网络 | 网络制作器实际委托子制作器，生成滑动窗口组件，通过验证发布后再组装调用 | 已记录父／子任务 |

入口目录、工具/模块统一打包、真实磁盘预设、委托开关的宿主拒绝、同前缀分叉、只读参考资料均已验证。网络制作器关闭委托时不能制作或登记新组件。

新增11份通用业务组件由制作 Agent 从标准脚手架生成；移动、位置资料是明确标记的参考修订，工具收集器等既有框架组件继续复用。标准脚手架并非零字节，参考修订不算作独立原创。每份产物有源码哈希和制作记录。小镇网络与出生模板由维护者用声明配置组装，不声称是网络 Agent 一次口语生成的完整成品。

## 应用运行

| 应用 | 验收 |
|---|---|
| NPC小镇：9地点、7居民、21初始节点 | 真实核心测试覆盖移动/预算/位置边/访客、交易生产修理、交流赠送权限、双方同意、10时刻孕期、出生、孩子下一时刻活动、节点增量存档和冷恢复 |
| NPC自然运行 | 修正宿主时限后连续5轮、每轮7名居民全部完成并闭环，最终tick为6；此前超时中断的tick保留，明确核对后开始新时刻，没有重放交易。真实发生采集、移动、出售和修理，重开后私人记忆、财产、位置及原生会话保留 |
| 真实模型出生 | 从已验收存档复制到期状态，由母亲Agent调用医院工具办理出生；孩子使用独立原生会话和记忆，父母私人记忆未被修改，冷恢复通过 |
| 固定讨论＋去中心化协作 | 三成员真实读板、发言和写私人记忆；两协作者并发认领并公告；版本冲突校验、组间范围与冷恢复通过。没有自主操纵网络的根Agent |
| 知识归档与恢复 | 真实管理员对话完成归档，重开后回忆私人笔记并检索资料；组件与网络测试覆盖修订、软删除和恢复。这是本地关键词检索，未迁移向量RAG |

NPC的自然选择不由框架保证：5轮自然运行没有自动完成婚姻，家庭业务另以到期场景测试。出生测试提示建议“小苗”，角色实际向工具传入“小满”；模板正确使用了真实工具参数。没有把“能办理出生”解释为模型一定服从命名或一定在指定轮数达成生活目标。

小镇tick采用按居民顺序连接，便于同一时刻内处理便条和业务。访问仍默认异步、信号仍按同层屏障执行。相互等待整轮结束的模型活动不适合放在同一层；本轮没有为此改变核心锁语义。地点访客可以从自己的位置出边派生，出生无需另写名单同步代码。

## 框架与宿主改动

核心目录相对基线仅修复参数传递内部形参冲突，保证key/self/function等业务参数原样传递。其余改动位于制作扩展、通用组件、Harness适配器、客户端及配置：

- 当前网络复制与试装、候选网络测试、复用配置书签；正式网络不自动修改。
- 执行器配置、操作参数、暴露工具与依赖在发布/应用前检查；拒绝猜测的prepare形式和不存在的expose工具。
- 原生SDK新版导出与workingDirectory服务装配，完整官方工具目录恢复。
- 原生进程关闭先完成双向回调，避免write-after-end；节点回滚复用未变化的日志前缀，变化才分叉。
- 运行时限从界面请求传到事件循环，空错误保持明确失败，不变成undefined成功；中断需显式核对再开新时刻。
- 配置书签保留目标已有授权与运行状态。

ctx与测试副本不等于操作系统安全沙箱；生成的Python组件仍按可信本地代码运行。模型制造结果必须看真实测试和业务覆盖，不能只看“验证通过”字样。
