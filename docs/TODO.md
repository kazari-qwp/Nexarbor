## 未来升级：多模态交互式网络画布

状态：已记录，待后续设计和实施。

目标：通过网络总览、局部展开和节点内容缩略图，帮助多模态 Agent 理解图结构、选择操作对象，并让用户直接观察和参与网络操作。

- 全景展示组织层级、网络分组、节点类型和运行状态。
- 局部展开节点邻域，分别显示管理关系、读连接、写连接及箭头方向。
- 为 Agent、文本、报告和离线网络提供职责、内容或拓扑预览。
- 将当前视图截图、选区和简短结构信息按需提供给模型，画面标识与实际节点 ID 对应。
- 图操作复用现有工具和授权接口，画布作为独立可拔插组件。
- 首阶段验证总览、局部展开、状态和截图读取；比较纯结构文本与结构文本加图像的任务表现、成本和错误率。

参考：

- https://github.com/DayuanJiang/next-ai-draw-io
- https://github.com/pskoett/pmx-canvas
- https://github.com/artokun/comfyui-mcp
