# Nexarbor 0.10.0

本次将项目完整迁移到新的模块化核心，整理为 domain、app、adapt 和前端四层。

- 节点、模块和工具使用新核心；保留节点锁、局部快照回滚及基于原生 DSH 日志的持久化。
- 讨论协作、资料库和 NPC 小镇三个应用已完成真实模型验收，随包交付初始状态和运行后状态共六份演示。
- 最终小镇为 45 个节点、7 个 Agent，已运行至第六天、30 时刻；最终 Agent 可双击查看原生消息历史。
- 上下文组装器显示为小矩形。左键点击进入该模块的频道局部视图，支持返回全局和工作区恢复；沿用已有亚节点筛选。
- 清理七个无用通信节点，更新两个制作 Agent 的工具、提示词及学习文档。

## 安装

下载 `Nexarbor-0.10.0-win-x64.zip`，完整解压到新目录，双击 `Nexarbor.exe`。

包内包含 Electron、Python 和基础依赖。运行 Agent 仍需本机安装 Git for Windows 与 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)，并配置可用的模型连接。可选本地向量依赖见包内 `docs/INSTALLATION.md`。

这次是核心结构的破坏性重构，原项目请先保留副本；建议直接打开随包演示或按新格式迁移。当前默认模型推理强度为 high。

发布前已通过 526 项 Python 测试、137 项前端测试，以及实际桌面客户端的六份演示和历史查看验收。此次发布验证不调用付费模型、不推进小镇时间。

附件中的 `SHA256SUMS.txt` 用于校验 ZIP；`VERIFICATION.json` 记录该发布包的具体检查结果和打包工作树信息。
