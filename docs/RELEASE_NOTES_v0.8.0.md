# Nexarbor 0.8.0

织林现以独立桌面工作台发布，Agent 执行统一使用 DeepSeek Harness。

- 可视化网络编辑、拖拽装配、资源管理、书签与配置历史。
- 模块／工具制作 Agent 与网络预设制作 Agent，可围绕当前网络和选中内容咨询、修改并在副本中测试。
- 独立亚节点、私有出边、通用四路上下文组装与可配置频道名单。
- 每个项目独立保存模块、工具、网络和上下文位置，通过真实 Git Commit 与分支管理版本。
- 网络预设支持重复单元数量，覆盖固定讨论组、协作组、知识归档和 NPC 小镇等组合。
- 运行包内置 Electron、Python 与基础依赖；可选向量模型按需安装。

安装要求：Windows x64、Git for Windows，以及已安装并完成账户授权的 DeepSeek Harness。完整解压 ZIP 后双击 `Nexarbor.exe`。详细装配与授权位置配置见压缩包中的 `docs/INSTALLATION.md`。

0.8 直接运行桌面客户端。此前插件包的发布与标签已撤下，独立 Python Agent 执行器已移除。旧版本历史代码仍保留在 Git 提交历史中。
