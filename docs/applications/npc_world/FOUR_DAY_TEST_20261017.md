## 失败与测试入口修正

两次活动未正常结束均为铁匠：第2天早上（tick5）及傍晚（tick8），达到16请求上限。日志显示反复尝试旧交互入口，并在本时刻主要行动已用后继续尝试；这是明确保留的负面结果，没有靠扩大请求预算消除。

166次工具拒绝/错误中，102次为主要行动额度已用，50次为过期/不可达入口或对象离开，7次为交谈上限；另有2次把显示名当节点ID、3次铁匠不在店内、1次重复购买工具、1次体力或耐久不足。这些均没有越权执行成功，已经完成的业务也未被撤销。

旧测试脚本在首次单人预算耗尽时把整轮判为失败而退出。改为记录单人失败、继续有限时刻运行后，沿同一个根会话、原生日志和磁盘网络从tick6恢复，未重跑前六时刻。铁匠在下一时刻恢复正常活动；其他居民持续运行。报告和原始日志保留中断及两次失败，因此四天“完成”不等于“140次活动全部通过”。evidence.completed=true，evidence.passed=false。

本次没有修改NPC提示词去限制反复尝试；若后续优化，优先分析主要行动额度已用后的重复调用及旧现场信息，不应先扩大执行上限。
