# 住所、休息权限与场所元数据审阅

2026-10-16。新增规则全部位于NPC扩展，复用capabilities/node_metadata，不修改核心。

## 登记与权限

- 居民楼1：林舟、月宁。
- 居民楼2：阿森、石岩、老锤。
- 小路无登记住所。
- 新生儿随孕育方的住所登记，无住所时再尝试另一位家长。出生后住户元数据自动包含儿童，系统人格补充对应住所。
- 住户列表表示登记居住者，与当前是否在场无关。楼的地址与业务节点通过公开place命名空间计算residents，条目含node_id/name。NPC私人身份命名空间保持原有权限。
- 铁匠铺地址与业务节点通过同一place提供器返回materials（wood/ore），直接读取smith_stock，不维护第二份库存。
- 入队与结算都校验本楼住户；经过、进入其他楼不受限制。医院只保留生产，不再提供普通休息。无新增睡眠工具。

## 修改后的工具描述原文

`rest`：**在自己居住的居民楼休息，恢复体力。**

```text
# 小镇常识（只读）

这里是一个演示小世界，规则不必符合现实生理和地理。世界事实由工具结算，个人记忆和传闻可能不准确。

一天有早上、中午、下午、傍晚、午夜五个时刻。每个时刻可交谈最多三次，选择一个主要行动；也可以等待。结束本次活动前可以改行动，正常结束后框架自动记录。所有居民处理完才统一结算，业务使用时刻开始时的位置，然后一起移动。

本世界的居民不需要睡觉，晚上和午夜也可以正常活动，不必为了过夜返回住处。只有需要恢复体力时，才按自己的安排前往可休息的场所。

地点：民政局办结婚；酒馆喝饮料；居民楼休息与登记家庭计划；铁匠铺修工具；商店买卖；矿坑挖矿；树林砍树；医院提供生产服务。移动一次走一条道路。只能使用自己所在场所的业务，与同场所的人交流。

体力上限5，只能在自己登记居住的居民楼休息，每次恢复3；其他居民楼可以经过、探访，但不能在那里休息。居民楼的住户名单和铁匠铺的剩余材料可通过节点元数据查看。具体职业经验、家庭和身体状态相关知识按身份分配，可从自己的知识节点读取；场所服务、价格与库存以当地工具为准。

位置、资金、体力、物品和家庭关系只能通过获准工具改变。你的私人记忆仅供自己读写，其他居民看不到；世界常识不能修改。收到的交谈是对方说的话，不自动成为世界事实。
```
