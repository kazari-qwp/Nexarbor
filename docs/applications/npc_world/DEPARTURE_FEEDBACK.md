# 交谈对象离开后的反馈（2026-10-17）

只修改交谈不可达时的反馈，不修改移动次数和轮次结束规则。核心不增加 NPC 逻辑；tool_assembly 仅增加拒绝后的通用文案钩子，NPC 应用负责解释，不能通过钩子放行调用。

## Agent 实际收到的新增文案

当 NPC 曾同场看到对方离开时：

```text
{姓名}好像已经去了「{当时看到的目的地}」，已经不在这里了。
```

实例：

```text
老锤好像已经去了「酒馆」，已经不在这里了。
```

没有可用的同场离开观察时：

```text
{姓名}已经不在这里了。
```

这些文本作为原有工具失败结果返回，原生客户端可能附带 Error 前缀。消息未发送，不消耗交谈次数，不额外唤醒模型。工具描述、NPC 指南和系统提示没有修改。

## 信息范围与存档

成功移动时只为原地点当时在场的居民保存一条离开方向观察。后续无人看见的移动不会更新旧观察；回复中是上次看见的去向，不是全局实时定位。返回同场后清除旧离开观察。观察随居民模块状态一起持久化，并参与现有行动事务回滚。

同场但权限撤回、定义变更、目标被卸载等情况保持原拒绝，不伪装成目标移动。移动业务本身不因该反馈获得额外访问权限。

## 验证

六项邻域测试通过，新增覆盖：真实移动导致交谈失败的自然语言、失败不投递/不扣次数、后续不可见移动不泄露目的地、观察持久化、无观察时降级、定义变化保持原拒绝，以及移动失败回滚不残留虚假观察。没有调用付费 API。
