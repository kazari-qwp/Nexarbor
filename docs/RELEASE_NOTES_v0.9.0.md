# Nexarbor 0.9

- 可在项目首页和设置菜单选择、保存本机 DeepSeek Harness 路径。
- 默认上下文 600k、最大输出 50k，统一写入 `configs/agent-defaults.json`，普通节点与两个制作 Agent 共用默认值，独立设置优先。
- 运行包和仓库新增 `项目演示/`，提供讨论协作、资料库、小镇各自的初始／最终状态；包含实际业务结果、会话分块和协作 Git bundle。
- 节点对象访问、上下文组装与工具收集使用一次频道广度遍历取得的对象表。
- 更新四个渐进式 Skill、基础机制说明及新版小镇样板。
- 改进高对比度连线与稠密整理；修复对话发送黑屏、重复 UUID 停用通知和切换频道后的连线缓存。

需要 Windows x64、Git for Windows 和 DeepSeek Harness 0.2.1 或兼容版本。内置 Python 与基础依赖，无需单独安装 Node.js/Python。API key 与本地模型不随包分发。完整解压后启动 Nexarbor.exe；安装、配置和演示用法见 INSTALLATION.md。

三项应用兼容性实测使用 DeepSeek Flash。讨论协作通过 CSV 转 JSON 的 18 项独立检查；资料库完成六阶段流程并通过两次反馈关闭剩余入库项；小镇完成五天 25 个时刻及重启恢复。上述结果针对已测流程，不保证任意任务一次完成。开发验收报告和原始测试日志不随包发布。
