# NPC 显式节点模块重构

用户已授权实施：删除 Start；删除轮次收尾/统一业务结算；其余应用功能拆成显式装配在节点上的模块。

- 核心增加通用节点模块注册、装配、恢复和卸载生命周期；配置及状态随网络持久化。
- 磁盘初始网络文件包含节点、连接、模块参数/初始状态及文本文件；通用加载入口读取它，不再写世界构建器。
- 地点移动、居民状态与交流、住户与休息、库存交易、修理、采集、双向同意、孕期与出生分别装配。节点采用普通 Node/AgentNode，不再依赖 WorldNode.place/kind/Resident 子类。
- 业务工具成功即生效；失败不扣行动额度、不部分扣资源。移动立即改变在场连接。每时刻一个主要行动，交谈最多三次。
- 时间文本模块在收到新脉冲时推进时间；居民执行模块通过正常 Agent 结束记录完成。脉冲层屏障负责等待，无轮次收尾/业务结算回调。
- 上下文、身份元数据、会话装配均按显式挂载处理，复用既有上下文装配器/信号响应器/Agent 执行器。
- 新生儿是普通 Agent 节点，装配儿童配置；只在下一次脉冲加入。
- 最小模拟测试及原生 Harness Mock 单NPC连接测试；禁止全世界真实API运行。最后提交，报告原功能到新模块对照及Agent文案原文。

当前核心持久化已有增量日志和全量快照；原生上下文游标捕获/分叉仍是独立待办，不混称已完成。
