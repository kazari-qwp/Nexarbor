# 编辑器删除、连接与子网书签

2026-10-18，基线 235ff44。只改客户端与编辑器服务，不改核心，不迁移旧组件。

## 用户确认的方向

- 默认组件文件列表只列组件自身文件；AGENTS.md、两份制作规范、依赖与旧参考留给制作 Agent，另设只读资料入口。不能用单纯调整排版代替内容分离。
- 增加工作副本删除、可选文件删除，先归档到工作区回收站；保护必要文件、只读资料、运行中任务和过期编辑。
- 节点编辑区提供新增连接、出入边列表；节点右键拖到目标打开连接设置。Ctrl+S 保存草稿，Delete 删除选中元素，文本输入和弹窗内不触发画布快捷键。
- 书签 A 复制选中节点，只保留内部出边；B 保留内部及外部出边。粘贴时内部目标改为新编号，外部目标保持原编号。两种模式用背景色和文字标记区分。
- Shift 点选可累加或取消节点和边。Shift 滚轮在当前可见图上按二部邻接“节点—边—节点”逐层扩缩，优先精确撤销最近一次扩选。
- 书签拖入画布生成独立副本；配置和本地文档复制，不复用原生 Agent 会话。A/B 在画布、悬停书签或历史条目时生效。纯边单独复制，不暗中扩充选区。
- 旁边历史区显示最近创建、使用的节点、边、书签；点击定位，和撤销分开。书签与历史作为工作区编辑资料持久化。

## 后续补充（同轮继续实现）

- 悬停书签按 A 或 B 删除；同一选区连续相同键两次取消刚创建的书签，交替 A/B 不取消。自动按键重复不算第二次。中键重命名，名称仅悬停提示。
- 历史条目悬停 A/B 可复制。单独选边也能生成边书签；单点、单边、A 内部子网、B 保留外联子网共四类筛选。
- 用户纠正纯边复制：A/B 都不保存起点；A 只保留 metadata，不保存终点；B 保留终点。拖到节点上以该节点为新起点；缺少端点则打开连接设置，不能沿用旧起点。
- 自定义书签分类，新增书签进入当前分类；分页显示，不因过多删除书签。复杂子网显示简易 SVG 缩略图。
- 历史保留最近 100 项，超出删除最末尾；仅真正拖动使用或创建节点／边、拖入书签时更新。添加、删除、重命名书签、简单点选、分类管理都不更新历史排序。
- Ctrl+Z/Ctrl+Y 接入画布、布局、书签增删改和粘贴的撤销／重做；输入框和源码编辑器保留原生撤销。
- 增加客户端设置页，集中配置上述所有键盘与鼠标快捷操作，保存在工作区编辑资料内；文本编辑器保留自己的撤销行为。悬停删除默认跟随 A/B 绑定，也允许独立指定删除键。

## 当前进度

上述功能已实现。书签、分类、历史和快捷键设置保存到当前工作区的 `editor-library.json`，与运行网络快照分开；历史最多 100 项，书签每页 6 项。修改书签使用期望旧值检查，快速复制及撤销按顺序处理。

纯边拖入时，不完整的端点通过连接弹窗补齐；B 拖到节点且目标仍存在时可直接连线。节点副本生成新编号，内部出边重映射，B 的外部出边保持原目标；已消失的外部目标不重新创建。文件进入独立副本目录，模块中声明 `format: node-id` 的配置字段随编号映射，任意业务字符串不自动替换。

删除工作副本或可选源码文件先移入当前工作区的 `studio/trash`，不删除已发布版本；必要入口、清单、示例及制作资料禁止删除。默认源码列表排除宿主指南，制作 Agent 仍能读取这些真实文件，客户端单设只读“制作资料”页。
