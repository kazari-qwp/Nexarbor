# 统一节点、网络预设与配置历史

2026-10-18，基线 54e1393。仅改编辑器、资料服务和组件制作流程，不改核心访问／信号语义，不迁移旧应用。

- 基础节点与工具、模块共用资源管理器栏目，可分类、拖入画布；单击右侧编辑待放置节点，Save 保存独立书签，不创建运行节点。
- 删除左侧大型组件工作室入口。模块目录每一级提供“制作新模块”，新工作副本记住发起目录，发布成品默认进入该目录；目录已删除时回到根目录。
- 网络预设也使用相同栏目，拖入会添加网络，保留场上原网络。网络书签悬停 S／右键保存到当前预设目录；A/B 的快照与模式原样保存，放置时按现有规则清理陌生节点连接。
- 书签右键菜单提供保存和删除。S 可自定义，纯资料管理不影响撤销或使用历史顺序。
- 历史保存独立节点／子网／文档／布局／边快照；拖放与复制直接用缓存，不回查原件。删除原节点、书签或预设不妨碍历史复用。
- 历史按配置归并、按实际使用移到最前；节点实例 ID、画布位置、上下文游标和运行状态不作为配置身份。工具引用、模块种类、配置与访问授权仍属于配置。
- 所有来源的每次放置都生成新的内部节点 ID，检查冲突并重新映射内部引用；名称保持原样，不加“副本”。
- 预设与成品共用 `{network, files}` 网络文档，保存独立磁盘 `.json`，旁边 `.editor.json` 记录布局和复制模式。虚拟“已存储网络”及其子目录保存到工作区 `network_presets/networks/`，其他虚拟目录保存到 `network_presets/fragments/`；分类不移动文件。“保存全网”默认归入“已存储网络”，完整网络也可拖入画布当零件。

实施顺序：共享资源结构与持久化 → 制作目录、历史缓存与配置键 → 统一浏览与待放置编辑 → 独立 Electron 端到端验证与原交互回归。所有数据及测试位于 E 盘；不调用模型。

## 已配置单节点预设（2026-10-19）

- 节点栏分为系统“官方节点”和“已保存节点”目录；自建虚拟分类仍使用原有新建、重命名、剪切／粘贴与拖放操作。
- 从画布把配置好的单节点用 A／B 存为书签，悬停按 S 或右键“保存”，即可写入当前节点虚拟目录；浏览节点根目录或官方目录时保存，自动归入“已保存节点”。节点右侧待放置编辑器的 Save 也先生成书签，再按同样方式登记。
- 保存完整节点快照：节点类型、名称、描述、参数、模块及其配置／状态／访问授权、提供的工具及频道、工具箱、暴露项、Agent 配置／执行绑定／输入状态，以及节点引用的文档正文。全网传播中的信号和宿主会话不属于可复制节点；沿用已有书签规则，新实例不复用旧上下文游标。
- A 仅保留书签内部连接（单节点的自环也会保存）；B 同时保存外部出边。放置时给节点和关联文档分配新身份，自环与显式内部引用映射到新节点；B 外联仍指向原目标，目标不存在时清除该出边。
- 正文与完整网络使用相同 v8 `{network, files}` 格式，实际写入工作区 `node_presets/nodes/<编号>.json`，旁边的 `.editor.json` 存名称、布局、A/B 模式、来源书签与显示目录。节点文件与 `network_presets/` 中的网络文件独立，只有根节点的完整网络仍属于网络预设。
- 同一书签在同一虚拟目录重复保存覆盖原预设，不重复登记，也不移动使用历史或加入网络撤销队列。节点模板和关联文档拥有独立快照，不依赖原节点、书签或历史条目的存在。
- 官方节点只可归档／恢复。自存节点可归档、恢复和确认后彻底删除自己的两个预设文件，独立书签／历史缓存仍保留；保存的节点仍引用某个模块或工具时，阻止彻底删除该实现。
