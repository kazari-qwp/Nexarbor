# 组件制作 Agent 与可选模块前端

2026-10-18。基线 c0bc7ca。用户要求更新制作 Agent 以适配现有核心，文档统一使用中文；每个模块可选携带自己的前端，客户端按模块折叠挂载。元数据字段可通过加号逐项添加。

## 实施约定

- 保留 v3 固定 execute(ctx, activation) 协议。清单可选 frontend:{entry,title,height}，入口为组件内自包含 HTML。普通 Python 组件不依赖浏览器；无前端仍用现有 JSON Schema 表单。
- 客户端提供统一页面容器和消息桥。页面读取所在模块的配置、状态、节点基本标识及配置 Schema，只能提交该模块的新配置；不接触宿主令牌、网络授权、任意 RPC 或其他节点。
- 页面使用独立 iframe，允许脚本而不授予同源、终端和网络访问。通过受限的页面资源地址加载，沿用客户端的草稿、校验和应用流程。
- 工作室可编辑、预览、验证、发布前端；发布指纹包含页面源码，修改页面后必须重新验证。界面可选，不提高运行权限。
- 制作 Agent 的职责、核心 API、节点锁、输入与元数据、前端协议和验收要求均用中文说明。新任务刷新规范文件；前缀改变后拒绝继续旧历史，避免拿旧 API 制作组件。
- 先用元数据编辑页示例验证加号、类型、增删、折叠、配置持久化与非法配置拒绝。复用现有元数据发布机制，不迁移前两个应用；若新增业务模块，交给制作 Agent，不手写应用兼容代码。

## 验收

清单与入口路径检查；页面随发布包保存；无前端组件回归；消息来源及配置 Schema 校验；真实桌面客户端编辑与折叠；保存应用后重启恢复；Agent 提示词刷新与历史前缀失效。过程和结果继续记录在本文档。
