# 核心信号与脉冲节点实施计划（2026-10-16）

授权：直接修改核心，暂不迁移/兼容前两个应用；本轮不运行真实API，不运行NPC世界。仅修改E:/DataNet-模块化成品。

确认语义：接口=目标+结构化元数据。公私、门槛、倍率、频道及等待完成属性归元数据。频道为开放集合，任意相交即可通过，信号频道原样保留不收窄。信号只走公有、匹配频道的接口；读写访问保留自身权限规则。信号携带内容、真实来源、节点处理过滤条件和预算。

实现：核心不可变Signal/NodeFilter/InterfaceMetadata；异步广度逐层并行，节点完成后再转发，过滤未命中可中继，合流取最强输入不相加，每信号每节点一次。仅闭环源允许一次返回，不再次激活源；新脉冲用新ID/visited。冻结本轮拓扑，新节点下轮加入。非等待连接为终端通知，后台处理不阻挡就绪屏障，任务显式可等待/取消；严格完成顺序的中继连接必须等待完成。

核心PulseNode有频道/强度/内容/过滤器配置和序号/最近信号状态，显式有限次数/时限运行，返回后自动发下一轮信号。结算通过通用cycle_complete回调，完成后再发下一轮。不包含NPC、日期、Harness知识；时间文本将来由组件处理。

持久化：网络格式升级v4，不接受v3或旧接口字段；脉冲和信号记录纳入序列化。回调/原生句柄不序列化，重启后重新绑定；运行中记录标为interrupted，拒绝自动重放有副作用的处理。核心管理/节点创建操作同步采用新格式，不改应用兼容代码。

验证：纯核心离线测试，频道OR与保留、私有阻断、分层并行、激活过滤、权限不提升、合流不放大、visited环路与回源、预算/超时/取消/通知、拓扑快照、Pulse多轮/失败/结算回调、序列化与中断恢复；记录已知应用迁移边界。Agent可见文案有改动则原文交付。
