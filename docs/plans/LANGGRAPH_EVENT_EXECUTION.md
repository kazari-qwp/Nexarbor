# LangGraph 事件与执行图实施计划

官方 langgraph Python 包作为可选后端，不替换 Agent 循环、权限图或核心持久化。事件触发器选择执行图，模块执行器凭宿主授予的操作表执行，外部事件不能指定任意 Python 路径。

结构化配置支持 call、sequence、parallel、branch；每个分支封装为子图，未激活分支不参与汇合。每次调用拥有独立结果状态，等待整个执行图完成才向核心信号传播返回。同步模块在线程执行，超时后未停止线程阻止该节点重入。

迁移时钟、信号 Agent、五次存档计数器，删除旧 signal_response 组件，不提供旧接口兼容。支持节点 event.trigger 装配、普通应用事件和显式异步事件入口；应用事件在业务事务成功后触发。

测试：真实官方库的顺序引用、条件分支、并行屏障、汇合、失败和超时；脉冲→时间→并行 NPC→存档→脉冲；移动事件触发旧/新场所刷新→汇合；磁盘恢复和组件卸载。优先本地 Mock 原生 Harness，不运行付费完整世界。

不混入此前讨论的行动值调整，不修改现有六天世界存档。
