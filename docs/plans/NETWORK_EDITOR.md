# 网络编辑器实施计划

用户授权：2026-10-17。仅修改本仓库，先完成 NPC 小镇；无须发布网站或推送 Git。

## 目标与交互

通过本地前端从空网络创建可运行的小镇，无须编辑 Python/JSON 或重新编译业务模块。现有模块预先实现；前端编辑节点、连接、模块参数和资源。采用成熟图编辑库，优先复用 React Flow 等现有能力。

- 单击 Agent：显示真实访问规则计算的局部视角、可达节点和可用工具。
- 双击 Agent：打开绑定的真实 Harness 会话；未绑定时显式提示，不能伪造聊天。
- 按频道、节点类型、关键字筛选；提供全图/选中局部视角。
- 节点面板：身份、元数据、模块装配与参数、上下文资料、文本与人格。
- 连线面板：方向、强度、可见性、频道；界面选择不改变实际权限。
- 配置执行图、事件响应、四路上下文来源；提供模板及可展开的底层配置。
- 新建/导入/导出/校验/保存/恢复；运行、暂停、单步；区分草稿和运行状态。
- 当前小镇作为可导入预设；基础组件可组合成新小镇。

## 架构边界

核心保持通用。编辑器为可选扩展和宿主前端，复用核心序列化、权限遍历、组件清单、节点模块、执行图及持久化。后端是数据真源，浏览器不直接执行模块代码。模块配置 schema/默认配置以组件数据形式公开，表单由此生成。运行期间拒绝危险结构编辑；并发修改用版本检查。

Harness 模式必须使用当前 adapter/backend/真实会话，双击导航使用宿主已验证的页面地址；本地独立模式供编辑与确定性最小验证，不冒充真实模型运行。监听仅本机、同源检查和随机访问凭据，不能把任意文件读取/命令执行暴露为 HTTP。

## 实施阶段

1. 检查核心、组件目录、Harness 会话导航/桥接，确认最少必要接口。
2. 建立编辑器组件、可编辑配置及 schema 目录、完整预设和可组合模板；实现校验、资源路径约束、持久草稿和应用。
3. React Flow 前端：网络画布/筛选/局部视角/属性表单/连线/模板/文档/执行图/状态栏。
4. 对接真实 Harness 会话、执行控制和存档；无宿主时明确离线编辑状态。
5. 从空网络通过前端操作建立两个场所、两个 NPC、一套脉冲/时钟及一项业务，验证移动/交谈/行动值和保存恢复；另检查完整小镇导入。
6. 开独立任务测试客户端，保留所有 Agent 会话左侧可见；优先 Mock/确定性测试，不运行无上限付费世界。
7. 保存测试证据、实现记录和操作文档，列出所有 Agent 可见文本改动；本地 commit，不自行 push。
