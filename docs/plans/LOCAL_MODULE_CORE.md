# 局部模块核心改造（2026-10-18）

本轮仅改核心、标准模块契约和官方扩展访问组件，不迁移旧应用，不保留旧模块构造器兼容。

## 约束

- 普通模块只获得自己的配置、状态、所在节点的信息和受限上下文，不获得 Backend、Network、Node、Application 或 Harness 实例。
- 网络访问从装配节点出发，频道与强度由装配配置授予；嵌套调用继承剩余范围，不能借其他普通组件扩权。
- 信号回调只收到不可变信号和投递数据；响应采用接收模块自己的授权，不继承发送者权限。
- 跨组件只调用公开且带频道的操作，返回 JSON 副本，不返回组件实例、状态引用或可执行对象。
- 官方 network.gateway 通过宿主注册，显式授予操作和目标，默认不加载、不装配。普通模块只有显式可达该接口才可使用其扩展能力。
- 所有回调、异步等待和卸载后的旧引用均要检查生命周期与调用范围。

## 验证

测试默认拒绝、频道/强度、跨组件转调、异步、信号并行与层屏障、生命周期、快照重载、官方网关显式授权与撤销、旧契约拒绝。

同进程 Python 仍是可信宿主代码：本轮建立框架接口边界，不宣称可防御恶意 Python 的反射、任意导入或系统调用。操作系统级不可信代码沙箱是独立工作。
