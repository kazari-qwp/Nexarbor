# Nexarbor 0.8 网络工作台

工作台使用 v8 网络格式与 v3 模块协议，Agent 执行统一连接 DeepSeek Harness。安装和源码装配见 [安装指南](INSTALLATION.md)。

![NPC 小镇工作台](images/nexarbor-town-workbench.png)

## 从项目开始

双击 `Nexarbor.exe`。未指定有效项目时，首页提供“打开项目文件夹”和“新建项目文件夹”；顶部“工作台”菜单也提供这两个入口。新建项目会初始化 Git、资源目录、项目清单和 `打开项目.cmd`。

项目资源从自己的文件夹读取。资源库中的模块或工具可通过下载箭头复制到当前项目，此后使用项目内的实现版本。缺少模块时，网络仍可打开，受影响的节点显示问题；启动失败的简略原因会显示在首页。

## 画布与装配

从左侧拖入节点、模块、工具或网络预设。拖入工具会加载对应模块，拖入模块会补齐工具与递归依赖；节点内已有装配会去重。单击选择对象，在右侧工作台编辑；双击 Agent 打开对话。

圆形节点在选中或悬停时显示工具、模块数量，点击对应按钮可跳转工作台。依赖数量可展开列表，条目支持跨资源栏定位或在工作台中跳转；左箭头返回上一级。模块与工具在悬停时显示名称和描述。

亚节点用较小的矩形表示，可以挂在普通节点或另一亚节点上，拥有独立模块、工具和出边表。归属虚线不是真实业务连接。两个配置开关分别控制借用父对象出边、向父对象开放出边，详见 [亚节点](SUBNODES.md)。

资源列表采用路径导航和文件夹操作，支持多选、剪切粘贴、拖拽、重命名与归档。文件夹非空时不能删除，可剪切目录及子目录中的全部资源后整理。归档页面可以恢复资源；只有用户拥有、且已无依赖的资源可以彻底删除。官方工具受到保护。

## 选择、连线与查看

画布右键菜单支持咨询 Agent、删除，以及保存带外联或不带外联的书签。重叠连线通过列表选择。拖入纯连线模板后，终点跟随鼠标，左键节点完成连接，左键空白取消。

包含唯一一条无头入边的节点或网络书签，可拖到已有节点上，把该节点绑定为入边起点；多条无头入边不做自动绑定。复制或拖入始终分配新 ID；内部连接指向新副本，保留外联时仍指向原有外部节点。

左右侧栏可折叠并拖动边缘调整宽度。显示筛选可按节点类型和频道收窄画面，全图与局部视角支持快速切换。窗口调整大小时画布同步适配，小地图跟随当前视图。

## 书签、历史与预设

书签保存配置与独立数据快照。历史同样保留独立快照，按配置去重，最近使用的条目提前；选择与单纯的书签管理不进入画布撤销队列。文本和数据副本具有独立存储，复制 Agent 不继承会话。

节点、边、网络、工具和模块均可在底部筛选。模块和工具采用不同背景色；有模块预览图时显示图片，否则显示名称。悬停显示名称和描述，中键可重命名。

网络书签上按 S，或右键选择保存，可生成磁盘上的网络预设。当前虚拟分类位于“已存储网络”内时，文件保存到 `network_presets/networks/`；其他分类保存到 `network_presets/fragments/`，并保留当前虚拟分类位置。

支持数量参数的预设，在右侧填写可重复单元数量后拖入。成员逐个生成，公共资源共享，内部 ID 和明确引用自动重新映射；详见 [预设参数](PRESET_PARAMETERS.md)。

## 编辑、运行与版本

- **校验并更新网络**：校验当前草稿，并把编辑装配到运行网络。
- **Commit**：通过真实 Git 保存项目版本，包含资源、网络、数据和 Agent 上下文的日志位置。未变化的数据复用已有 Git 对象。
- **另存为 / 导入**：导出或恢复完整网络及可携带的上下文。修改后继续运行可建立上下文分支。

退出前的页面、选择和画布位置会恢复。左侧底部提供脉冲的单步、运行与时刻数量。文本和数据节点的工作台提供红色清空按钮，立即清空存储数据并保留其他配置。

启动先显示窗口，较重资源按需准备；切换网络的加载提示限制在画布区域。向量检索在首次实际使用时准备可选运行时与模型，其他界面请求可以继续响应。

## 与制作 Agent 协作

顶部 Agent 菜单提供“组件／模块制作 Agent”和“网络预设制作 Agent”。右键资源可咨询组件制作 Agent、咨询网络 Agent，或建立修改分支；画布右键可带着当前选择询问网络 Agent，整个网络也会进入咨询范围。

制作界面以对话为中心，支持图片、链接与文件引用。代码在右侧按需展开，边界可调整宽度。修改在工作副本进行，已有发布版本保留；可复制当前网络到测试环境，在副本中验证后再采用。
