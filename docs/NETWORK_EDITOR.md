# Nexarbor 0.8 网络工作台

工作台使用 v8 网络格式与 v3 模块协议，Agent 执行统一连接 DeepSeek Harness。安装和源码装配见 [安装指南](INSTALLATION.md)。

![NPC 小镇工作台](images/nexarbor-town-workbench.png)

## 从项目开始

双击 `Nexarbor.exe`。未指定有效项目时，首页提供“打开项目文件夹”和“新建项目文件夹”；顶部“工作台”菜单也提供这两个入口。新建项目会初始化 Git、资源目录、项目清单和 `打开项目.cmd`。

项目资源从自己的文件夹读取。资源库中的模块或工具可通过下载箭头复制到当前项目，此后使用项目内的实现版本。缺少模块时，网络仍可打开，受影响的节点显示问题；启动失败的简略原因会显示在首页。

## 画布与装配

从左侧拖入节点、模块、工具或网络预设。拖入工具会加载对应模块，拖入模块会补齐工具与递归依赖；节点内已有装配会去重。单击选择对象，在右侧工作台编辑；双击 Agent 打开对话。

圆形节点在选中或悬停时显示工具、模块数量，点击对应按钮可跳转工作台。依赖数量可展开列表，条目支持跨资源栏定位或在工作台中跳转；左箭头返回上一级。模块与工具在悬停时显示名称和描述。

亚节点用较小的矩形表示，可以挂在普通节点或另一亚节点上，拥有独立模块、工具和出边表。归属虚线不是真实业务连接。两个配置开关分别控制借用父对象出边、向父对象开放出边，详见 [亚节点](SUBNODES.md)。

资源列表采用路径导航和文件夹操作，支持多选、剪切粘贴、拖拽、重命名与归档。文件夹非空时不能删除，可剪切目录及子目录中的全部资源后整理。归档页面可以恢复资源；只有用户拥有、且已无依赖的资源可以彻底删除。官方工具受到保护。

## 选择、连线与查看

画布右键菜单支持咨询 Agent、删除，以及保存带外联或不带外联的书签。重叠连线通过列表选择。拖入纯连线模板后，终点跟随鼠标，左键节点完成连接，左键空白取消。

包含唯一一条无头入边的节点或网络书签，可拖到已有节点上，把该节点绑定为入边起点；多条无头入边不做自动绑定。复制或拖入始终分配新 ID；内部连接指向新副本，保留外联时仍指向原有外部节点。

左右侧栏可折叠并拖动边缘调整宽度。显示筛选可按节点类型和频道收窄画面，全图与局部视角支持快速切换。窗口调整大小时画布同步适配，小地图跟随当前视图。

## 书签、历史与预设

书签保存配置与独立数据快照。历史同样保留独立快照，按配置去重，最近使用的条目提前；选择与单纯的书签管理不进入画布撤销队列。文本和数据副本具有独立存储，复制 Agent 不继承会话。

节点、边、网络、工具和模块均可在底部筛选。模块和工具采用不同背景色；有模块预览图时显示图片，否则显示名称。悬停显示名称和描述，中键可重命名。

网络书签上按 S，或右键选择保存，可生成磁盘上的网络预设。当前虚拟分类位于“已存储网络”内时，文件保存到 `network_presets/networks/`；其他分类保存到 `network_presets/fragments/`，并保留当前虚拟分类位置。

支持数量参数的预设，在右侧填写可重复单元数量后拖入。成员逐个生成，公共资源共享，内部 ID 和明确引用自动重新映射；详见 [预设参数](PRESET_PARAMETERS.md)。

## 编辑、运行与版本

- **校验并更新网络**：校验当前草稿，并把编辑装配到运行网络。
- **Commit**：通过真实 Git 保存项目版本，包含资源、网络、数据和 Agent 上下文的日志位置。未变化的数据复用已有 Git 对象。
- **另存为 / 导入**：导出或恢复完整网络及可携带的上下文。修改后继续运行可建立上下文分支。

退出前的页面、选择和画布位置会恢复。左侧底部提供脉冲的单步、运行与时刻数量。文本和数据节点的工作台提供红色清空按钮，立即清空存储数据并保留其他配置。

启动先显示窗口，较重资源按需准备；切换网络的加载提示限制在画布区域。向量检索在首次实际使用时准备可选运行时与模型，其他界面请求可以继续响应。

## 模型与外部文本编辑

Agent 节点右侧的“模型”页可以独立选择服务商连接、模型和生成参数。连接旁的 **+** 用于添加新的 API 连接；同一服务商的不同 key 分别建立连接后，各节点互不影响。两个制作 Agent 也各有“模型”页，顶部“设置 → 模型与 API”提供项目默认值。密钥仅在本机加密保存，项目保存连接引用；切换模型或 key 后保留旧上下文并建立分支。

文本节点的“资料”页和节点右键菜单均可“打开文本文件”或“在资源管理器中显示”。项目文本保存在 `context/<网络标识>/`，Commit 记录原始正文；保存文件后同步到草稿，双方同时修改时可选择保留哪一份。“关联文本文件”允许引用项目外文件：运行时直接读取，正文不纳入 Git；打开加载后可“转为项目文本”。默认使用系统关联程序，可在顶部设置菜单指定外部编辑器。

## 与制作 Agent 协作

顶部 Agent 菜单提供“组件／模块制作 Agent”和“网络预设制作 Agent”。右键资源可咨询组件制作 Agent、咨询网络 Agent，或建立修改分支；画布右键可带着当前选择询问网络 Agent，整个网络也会进入咨询范围。

网络咨询、制作器和局部管理员共用 `inspect-network`（查看网络）Skill。会话起初只公布 Skill 名称和短描述；调用原生 `skill` 加载入口后，宿主才挂载观察工具。入口指导基本查询，复杂用法用 `read_skill_reference` 按需读三个任务参考；不会一次注入全部教程。

网络 Agent 通过命令观察网络，不操作键鼠。`view_network` 复用前端节点组件生成图片，默认折叠亚节点、隐藏纯资料文本；承载信号、工具或执行器的文本节点仍保留。图上用 N 编号表示节点，可按需显示 E 连线编号和频道；虚线只表示亚节点归属，不是实际网络连线。布局按连接关系和父子归属紧凑排列，并为节点和编号留出间距；过长的链折行。实线与箭头按起点节点稳定分色，颜色循环使用。相同方向的平行边合并绘制，标出数量，准确属性通过连线查询读取。

推荐按需查看：

1. `view_network {}` 获取完整匹配视图的图片和简短索引，选择和每轮快照一起固定。小图直接显示；文字缩小到不易读时，完整概览自动标出 R 区域框，返回 `view`。用 `view_network {"view":"概览返回的V编号","region":"R2"}` 按需取局部图。区域交替配色并附简短地标，框线错开描画；根据可读字号和完整节点覆盖选择尽量少的窗口，合并冗余稀疏窗口，相邻窗口约重叠 20%。区域节点数仅统计完整可见节点，边界裁切另计；局部沿用概览布局及编号，不重新排版；可临时加 `show_edge_ids/show_channels` 标注，无需重建概览。图片的文字索引最多列 24 个节点，不因此裁掉图中的节点；显式 `page/page_size` 才对图片分页。
2. 按 `nodes`、`hops`、`query`、`types`、`modules`、`channels` 组合筛选；`exclude_nodes/exclude_types/exclude_modules` 隐藏指定内容，`relations/exclude_relations` 按边关系筛选。`include_text=false` 隐藏全部文本，省略时默认保留活动文本；`include_subnodes` 展开亚节点。`channel_mode` 选择黑白名单，`direction` 控制邻域扩展方向。使用返回的 `view` 并提供新条件可连续调整视图，未提供的条件继承，数组替换而非追加，空数组清除；`reset` 清除指定条件。筛选会重新布局，编号不变；区域放大仍沿用原图。总览列出可用频道和边关系，供 Agent 发现实际命名。
3. `inspect_nodes {"nodes":["N3","N8"]}` 一次查看最多 12 个节点的模块表，另列亚节点的装配；`section=tools` 查看本地工具，`summary/settings` 查看归属、链接开关及执行绑定。`config/state` 分开读取配置和运行状态，可用 `modules/fields` 缩小范围。
4. `inspect_modules` 一次查看最多 8 个模块接口，按需读 Schema；`read_resource` 再按文件和行读取文档、源码。
5. `inspect_edges` 一次读取最多 24 条边，或按节点与频道分页查询。它保留精确方向、黑白名单、零值、阈值和倍率。图片中的 `!频道` 表示黑名单；频道统计明确区分允许和排除。

N 编号与真实节点 ID 绑定，筛选和布局不重排；新增节点继续递增，移除的编号不复用。每条实际连线都有独立 E 编号；未改变的边跨轮复用编号。查询可附 `snapshot` 防止混用不同轮状态。图片、文本索引和后续查询均来自同一快照；省略数量、分页和边界外连线明确显示。预设咨询默认观察该预设，制作 Agent 可分别观察候选网络、获准的当前网络、或测试副本；局部管理员仍仅能看到其可达的授权副本。

图片通过 Harness 原生图片内容块进入模型和可携带历史，按需启动隐藏渲染器，空闲后释放；失败会返回可继续查询的索引。已声明只支持文字的模型自动使用紧凑拓扑与分页。`read_network_text` 仅列快照内文件并按行读取，不能读取任意磁盘文件。旧 `inspect_network` 后端兼容接口保留，模型目录不再推荐全网原始 JSON 查询。视图缓存最多保留最近24个，受会话任务和快照约束；刷新或切换来源后重新取图。

节点对话、制作 Agent 和网络咨询共用标准 Markdown 渲染器，支持表格、列表、粗体、行内代码与代码块；链接和本地文件地址可点击。工具 JSON 默认折叠为摘要，展开后查看格式化结果；生成的原始 HTML 不执行。

制作界面以对话为中心，支持图片、链接与文件引用。代码在右侧按需展开，边界可调整宽度。修改在工作副本进行，已有发布版本保留；可复制当前网络到测试环境，在副本中验证后再采用。
