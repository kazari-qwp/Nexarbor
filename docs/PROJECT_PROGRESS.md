根节点工具箱已绑定经网络读取的合格率工具。Agent 类位于 datanet/agent/agent.py，节点默认 agent=None；仅根节点绑定实例，模型通过根工具箱调用统计，子节点保持确定性读取。保留 scripts/ 原 CLI 薄包装，测试仍集中在 tests/。

## 10. 最新完成：网络工具、Agent 状态简化与配置持久化

新增 applications/network_demo，根工具箱注册 describe_node、weak_read、strong_read，支持任意已注册起点。真实 API 实际调用三个工具，从 n1 弱读得到 1、2、4，强读得到 1、2、3、4、5、6，结果含首次发现路径。此演示的管理工具持有整个网络，尚无按调用者身份隔离的权限控制。

移除 agent_enabled 和切换方法，节点只通过 agent 是否为 None 表示有无 Agent；describe 中 has_agent 为即时计算值。绑定实例即可调用，移除后明确报错；保留实例引用再重新绑定可继续原会话。

datanet/serialization.py 实现 JSON v1 保存加载，支持四种现有节点和四种连接。相对数据路径以配置所在目录为基准，环、连接顺序及跨列表重复地址保留。只保存节点参数、连接及单值 JSON 数据；工具、Agent、密钥、历史均不保存。加载分两步恢复节点和连接，未知类型/版本、重复节点、悬空连接及非法字段会报错；保存先校验，再用临时文件替换。

实验三节点结构已保存至 applications/experiment/network.json，删除原装配函数中硬编码的节点与连接。装配层加载配置后绑定合格率工具，测试可覆盖存储路径。75 项本地测试通过，包括数字网络保存前后结果/路径一致、四种连接、存储读取、非法配置及配置驱动的实验统计。真实模拟数据快照 B 仍为有效 18、通过 9、失败 9、合格率 50%；未重新生成业务数据。本次配置迁移通过本地统计与模拟 Agent 回归验证，未再次请求真实 API。
