# 数据节点迁移与独立复制

2026-10-19，实施前检查点 `8240533`。沿用 v8 网络与 v3 模块协议；不添加旧应用协议兼容层。

## 已完成的结构

- 节点栏提供 JSON、CSV、SQLite、RAG、Wiki 五类官方数据节点。CSV 继续使用 pandas，SQLite 使用实际 SQLite 文件；RAG 复用现有 LlamaIndex 和本地嵌入模型；Wiki 复用原有页面、章节、链接及版本存储代码。
- 每个知识节点拥有自己的 KnowledgeStore 目录，不再把所有集合节点绑定到一个全局后端知识库。模块只能经 ctx 操作自身数据，外部访问仍按频道、强度和实际路径检查。
- 通用 `data.local` 模块提供结构、读取、查询、写入及只读开关。`data.knowledge` 递归依赖它，提供归档、历史、软删除、恢复、关键词搜索、上下文展开和索引更新。写入采用节点锁；失败可恢复旧数据。
- 右侧数据页可编辑已进场节点或待放置模板。编辑先在独立临时副本中进行，结果只加入草稿；等待期间节点配置或数据发生变化会拒绝合并，其他节点的草稿修改会保留。
- 第二应用配置 `configs/knowledge_v3/network.json` 加入五类已填好示例数据的节点，保留原有管理员、归档模块及私人记忆。运行仍只依赖网络配置、通用组件和框架。

## 复制的实际内容

文本与 CSV 正文、SQLite 二进制数据库、知识元数据库、原始资料、页面、历史与索引都包含在独立快照中。每次放置会重新分配节点 ID 和资源路径；空知识模板也预先获得独立目录。A/B 内部连接和显式节点引用映射规则保持原样，B 的外部链接仍指向原目标。

SQLite 采用在线备份读取一致快照，二进制数据以 base64 包装。知识目录按节点归属递归捕获。节点锁持久化使用旧资源镜像；回滚恢复数据库，并移除锁内新建的资料文件与失效缓存。Windows 文档路径统一使用斜杠，避免一个文件的两个别名在应用时相互覆盖。

缺少真实文件资源的复制会明确失败。用户 JSON 中普通的 `node_id`、`file_path` 等字段保持原值，不被猜成网络引用或文件句柄。书签、历史、节点预设、制作测试副本、管理员局部副本都携带相同数据；历史按内容归并，复制后的新资源路径不会使相同数据刷屏。

## 使用与边界

从“节点栏 → 官方节点”选择模板，在右侧填写数据，Save 为书签；悬停书签按 S 保存到当前自定义节点目录。拖入后打开“资料”页，按主键读写，保存草稿并应用网络。JSON 的固定键为 `value`，文本为 `content`，示例 CSV/SQLite 使用 `id` 主键。

RAG/Wiki 的向量检索需要配置本地 `embedding`。默认示例不写死机器上的模型路径；未配置时仍支持资料存储和关键词检索，语义请求明确报告缺少模型。验证使用已有 `build/models/bge-small-zh-v1.5`，没有付费模型调用，模型权重不随节点复制。

验证入口：`scripts/verify_data_nodes.py`、`frontends/network-editor/test/data-nodes.browser.mjs`；资源、历史与数据合并回归在前端测试目录。所有运行产物位于 E 盘 build，不操作用户实际数据做破坏性验证。

## 工作台清空数据

选中文本、JSON、CSV、SQLite、RAG、Wiki 或底层向量数据节点后，工作台各页顶部均显示红色“清空数据”按钮，不弹第二次确认。原有知识集合节点也支持。Agent 节点不显示此按钮。

已进场节点立即清空真实存储并持久化，同时清理草稿中的旧数据；不必先点击应用网络。名称、描述、连接、模块、工具及其配置均保留。JSON 值置空，文本正文及本地上一版备份清空，CSV 保留表头，SQLite 保留表结构，知识集合删除正文、历史版本、来源和索引但保留集合定义；底层向量节点移除全部索引版本并释放旧索引缓存。已有独立书签和历史快照仍是各自的数据副本。

待放置模板、尚未应用的新节点只清空自己的隔离数据副本。清空属于操作员动作，不受面向模块的只读开关限制；不会向 Agent 新增绕过局部访问规则的工具。

实际清空使用既有节点锁，等待先前访问完成，其他访问等待清空提交；失败恢复旧状态。运行期间其他节点发生变化时，不自动跨过该变化更新草稿基线，以免之后应用旧草稿覆盖新数据。目录删除前验证绝对路径、节点归属和内部链接，工作区管理目录不能作为清空目标。

清空专项验收：`frontends/network-editor/test/data-clear.browser.mjs`。覆盖实际红色样式、无确认弹框、没有数据模块的文本节点、未进场模板、未应用名称修改、刷新和冷启动。后端脚本另覆盖节点锁等待、故障回滚、原有知识模块及底层向量节点。
