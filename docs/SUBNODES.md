# 亚节点与独立出边

亚节点是核心节点容器，不是一种特殊模块。普通节点可用的模块也能装在亚节点上。它没有数据存储和散度，拥有独立的模块、工具、状态、权限和真实出边表。父节点的列表和数量不包含这些内容。

`parameters.parent_id` 指定归属，可指向普通节点或另一亚节点；允许未挂接的亚节点，不允许环。编辑器以小号紫色矩形显示，用无箭头虚线表示归属。虚线由归属关系生成，不是业务边，不单独加入书签或消耗强度。

两个开关默认关闭：`use_parent_links` 允许亚节点使用直接父对象的有效出边；`share_links` 把自己的出边及明确共享的后代出边开放给直接父对象。核心根据分别保存的表构造读取视图，去重同一条边。嵌套共享逐层生效，子对象不能绕过中间层向祖先开放。模块只调用 ctx，不管理这些表或开关。

## 本地调用

同一归属树内使用 `await ctx.local.call(module, operation, arguments, target=id)`；省略 target 时选择本容器上的模块，否则必须能找到唯一的本地模块。归属不增加寻路步数或消耗强度，不要求业务边和频道；模块操作的参数、权限、状态隔离和自身预算仍然有效。`$self` 和 `$parent` 可作为目标引用，后者适合保存后重新挂接的通用亚节点。

Agent 在 `execution.prepare` 显式引用装有上下文组装器的亚节点；执行器调用本地入口。需要收集亚节点的工具时，另在 `execution.tool_sources` 显式列出容器 ID。并未把亚节点的表复制进父节点。跨归属树仍经正常可达性和频道检查。

## 编辑与复制

父节点属性页可添加亚节点，再在亚节点自身的工作台装模块。Shift+滚轮从父节点扩展选择，一步直接到亚节点，不经过虚线。亚节点能进入书签、历史；复制父节点会带上后代，并重映射归属、prepare、tool_sources 等引用。单独保存亚节点时解除原归属，拖到其他节点会绑定新父对象；实际业务边仍遵循 A/B 复制规则。

频道过滤使用条目列表和加号，支持白名单与黑名单：空白名单不匹配，空黑名单不限制。信号发出的频道是标签而非过滤条件。旧节点和旧连线缺省沿用白名单，不改变原有行为。
