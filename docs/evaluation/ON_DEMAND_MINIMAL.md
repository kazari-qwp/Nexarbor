# 按需通信与讨论轮次最小验证

版本 0.3.11。修改位于独立的 agent_messaging 工具箱和 discussion_group 网络预设（含发言板节点），排障组件仅增加两项只读查询的允许列表。Python 基础框架、Harness 适配器和消息队列没有改动。

通过 4 项上下文合同测试：通讯录不自动注入、按需读取和压缩后的指南重载、消息提醒与读取、一次性回复及过期、讨论成员的权限边界、轮次及请求次数在尾部，以及只读查询在排障期间可用。

通过 4 项并行讨论/快照测试及 4 项指南路由测试。真实安装的 Harness 配合最终编译后端与模拟模型通过：新增查询工具、当前轮数存在于请求尾部且不进入会话历史、两类小组连续运行、原生路由及系统/工具追加、停用权限。
