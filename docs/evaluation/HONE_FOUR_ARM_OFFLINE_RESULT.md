四组开始时为工作区修改权限，用户随后手动改为完全权限；切换精确时刻未知。等待授权时间未扣除。客户端关闭web search/fetch，设置无下载环境及Python联网拦截，提示词明确禁止联网和已有实现。Windows原生沙箱没有操作系统级联网隔离。
