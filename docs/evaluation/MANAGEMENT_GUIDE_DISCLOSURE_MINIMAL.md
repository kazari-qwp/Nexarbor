# 管理总指南按需披露最小验证

2026-10-14。network_management Skill 组件监听 tool/before：首次使用管理工具或通道时加载同一个组网总指南。包括节点、Agent、网络、接口、预设发现、任务委托和小组启动。普通数据读写、记忆和成员讨论工具不触发。入口不要求先加载 Skill，也不改变工具授权。

文档沿用普通历史生命周期：已加载时不重复注入，压缩移除后再次操作重新加载。Skill 入口与直接工具入口使用同一个文档 ID 和正文。

验证通过：
- 四项 Python 最小测试：无 Skill 入口直接管理、重复调用不重复注入、已开放工具及讨论入口在压缩后重载、Skill 与直接入口共享指南、普通成员数据操作不触发。
- 实际 Harness 与新编译后端联通：根未获 Skill 工具仍通过直接管理入口取得总指南，模型请求中可见，历史仅保留一份；既有成员失败隔离和单人完成场景仍通过。

没有修改给 Agent 的描述或文档正文。编译后端同步到 adapters/harness/runtime/backend。
