## 2. 已有代码与可复用能力

| 模块 | 当前实际能力 | 后续用途 |
|---|---|---|
| config.py | 统一文件、数据库、提示词、工具路径 | 节点配置及项目定位 |
| analysis.py | 有效筛选、计数、合格率/有效率 | 实验数据节点的确定性工具 |
| rules.py | get_project_ids、单项目静态规则、规则转函数 | 精确规则节点后端 |
| tools.py | 读 CSV/规则、统计、返回 rule/sources | 第一批通用工具适配 |
| agent.py | API、多轮调用、白名单注册、参数检查 | 根 Agent 工具循环 |
| scripts/ | CLI、初始化、模拟生成 | 保留运行入口 |
| agents/ | 独立提示词/JSON 工具定义 | 通用工具与路由规则 |

现有 rules 表一个项目一条规则，没有时间版本。CSV 四列，没有实验时间。只有一个 analyze_project 对外工具。模型调用来自用户此前测试成功的反馈，本次未重新请求 API。

工具返回的是实际查询规则与文件/表/项目来源，没有文件哈希、全局节点身份或执行路径。代码尚无通用 query/get/write 协议。

## 5. 需要保留的工程问题

无工具调用直接输出并不保证数据已经查询；需要对应成功结果检查。当前提示词尚未明确各类问题的工具要求。API/文件/数据库异常、空正文和输出截断处理仍不完整。

SQL 规则查询未检查数据库是否存在，普通 connect 可能创建空文件。现有初始化无迁移机制，升级前备份，不直接删除旧表。尚无固定依赖清单、执行日志、边界/权限测试和独立评估集。

旧报告曾因 git status 报“must be run in a work tree”未确认工作区同步；本次未重新确认 Git 状态。之前提交 416d88e 已推送，不代表本次文档或所有最新代码已同步远程。
