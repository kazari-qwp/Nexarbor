# 模块局部视图与通信节点清理

保留现有“亚节点”筛选，没有新增筛选项。左键点击模块小矩形后，画布仅保留该模块、父节点，以及父节点通过模块声明频道直接连接的目标节点。显示对应频道的连线和模块归属线；多频道连接只显示与模块有关的频道。模块与连接的 allow/deny 设置均参与显示筛选。

右侧定位到父节点的对应模块。“全局网络”恢复整个画布；局部视图位置随工作区保存，关闭客户端后可恢复。所有投影仅影响前端，没有增加运行节点或更改访问权限。

清理了小砾通信、林通信、小路通信、阿森通信、阿石通信、老铁通信、悦通信。这些节点没有入边、模块、独立工具或数据。项目源、内置样例、初始演示和最终演示均同步清理；最终演示的活动保存网络也已处理。当前每份小镇为45节点、156条连接、7个Agent。其余节点记录、资源、Markdown和原生会话文件逐字节核对保持不变。最终小镇仍为tick30。

迁移脚本同时移除这些已经失去作用的旧通信亚节点，避免重新迁移时带回。对原项目只读归一化后，59个旧节点变为45个节点：7个工具亚节点的工具收集器已合并到父节点，另7个通信节点删除。
