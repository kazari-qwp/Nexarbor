# 固定讨论与 Git 协作

这是普通 Nexarbor 项目，业务模块和工具实现在本目录内。先复制整个目录到自己的工作位置，再在客户端选择“打开项目文件夹”；客户端会初始化独立 Git 和打开项目.cmd。

这是当前应用工作稿；完整业务兼容性验收尚未完成。

网络与受管理数据由 nexarbor.json 引用；modules/ 是模块源码，tools/ 是工具引用。模型授权与 API key 在本机配置，不随项目发布。

讨论成员只读访问用户任务资料；执行成员使用工作区工具完成真实 Git 协作。组入口由预设的匿名入口边标记，放置后将实际编号配置给根节点的运行编排器。
