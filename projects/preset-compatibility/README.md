# 预设组网兼容性验收

初始网络只有根 Agent 与局部网络管理员两个节点。讨论小组预设含 Leader、Recorder 和可调普通成员（默认 3 人）；执行小组预设含平等 Git 协作成员（默认 4 人）。modules/ 与 tools/ 保存完整依赖。

根 Agent 委托管理员使用两个预设还原固定架构，再运行讨论、任务认领、独立 worktree 提交、候选整合和全员验收。根只连接组入口，不连接执行组员。workspace/task/ 是 hone 的公开需求、接口和输入样例，不含旧实现或评测器。

context.network 是项目内的纯网络上下文组装器，支持四类上下文、内联文本及频道可达文本；不含文件系统扩展。管理员仍使用框架原有授权校验，不可装配官方越权模块。

复制整个目录后在客户端打开项目文件夹；本机模型连接和 API key 不随项目发布。

讨论成员只读访问用户任务资料；执行成员使用工作区工具完成真实 Git 协作。组入口由预设的匿名入口边标记，放置后将实际编号配置给根节点的运行编排器。
