# 局部网络管理员

挂载在普通节点上，按频道和强度收集可管理范围，将网络组装委托给网络制作Agent。调用方通过工具发现取得inspect/build/status/apply/cancel工具；build创建原制作工作副本，status读取原生会话进度，apply提交已完成的局部草稿。

模块入口在module.py；service.py组织委托、任务和范围；scope.py生成并校验别名视图；commit.py在节点锁及局部快照下提交或回滚。工作副本及制作工具复用app/studio，不在模块里实现第二套制作器。

旧无连线归属树权限已删除。允许访问的节点以access的实际遍历结果为准，范围外目标仅保留不可编辑引用。已有运行状态与工具实现保持，模块配置或显式安装/移除通过现有工厂和安装器执行。
