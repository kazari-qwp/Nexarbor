# 离线地震资料台：项目要求 v1

这是为知识库测试编写的虚构项目需求，不是 SQLite 或 USGS 的官方声明。技术资料和观测数据另有真实来源。

## 当前条件

- 项目代号：QuakeDesk。
- 需求版本：1。
- 部署在一台计算机上，观测资料和数据文件都保存在本机。
- 当前可用的 SQLite 版本是 3.44.0。
- 导出缓存保留 7 天。
- 没有指定项目负责人或承诺上线日期。

## 资料用途

观测记录会持续追加，需要按观测来源网、震级和时间读取、筛选与统计。保留 event_id 原文、数值精度和 UTC 时间，统计结论注明使用的资料范围。

文献目录是小型、相对固定的资料索引，需要保留 source_id 的前导零，并可作为表格交换。技术文档较长，既要能按主题找相关段落，也要能取回完整原文和出处。

请维护项目知识页和常见问题，整理当前需求、技术约束与资料解释。知识页应保留引用，后续需求或来源变化时可以修订；保留历史需求，避免把不同软件版本的说明混为一谈。

资料包含英文原文，使用者主要用中文提问。没有依据的信息应明确说明缺失。本次只建立和使用知识库，不开发 QuakeDesk 的程序。
