# 项目演示

每个应用各提供初始状态与最终状态，六个文件夹相互独立。先完整解压运行包，在客户端选择 DeepSeek Harness 路径并配置自己的模型连接，再打开项目或双击项目内的 `打开项目.cmd`。

| 应用 | 初始状态 | 最终状态 |
| --- | --- | --- |
| 讨论与协作 | 根 Agent、管理员与两个小组预设 | 管理员完成组网，讨论组维护公共笔记，协作组完成 CSV 转 JSON 项目并全员批准同一候选 |
| 资料库 | 四个启动节点，附原始公开资料 | 独立 CSV、SQLite、RAG、Wiki 集合，保留来源、历史版本、增量数据及交付文档 |
| NPC 小镇 | 新版小镇初始网络与开场动机 | 完成五天、25 个时刻，保留居民物资、关系、记忆与交流 |

最终状态保留运行结果和可携带会话分块，不包含本机授权、临时运行缓存及开发验收报告。上下文中的历史文字可能提到当时的工作路径；项目打开使用自身清单、数据与会话分块，不需要这些历史目录。资料库的本地嵌入模型不随包分发，需要时自行配置。协作组 Git 历史使用 bundle 携带，首次通过启动脚本恢复。

建议复制一份初始状态后探索；原始演示文件夹可随时重新从压缩包解压。默认上下文 600k、最大输出 50k，可修改运行包 `configs/agent-defaults.json`；项目和节点的独立配置优先。
