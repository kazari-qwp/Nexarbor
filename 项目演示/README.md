# 六份演示项目

每份目录可通过打开项目.cmd，或客户端首页“打开项目”打开。初始项目保留原起点；最终项目保存 Agent 的实际运行结果。双击 Agent 节点可打开对话，历史消息从当前机器的 DSH 日志读取。项目不含本机模型凭据，继续运行前在设置中选择可用模型连接。

| 应用 | 初始 | 最终 |
| --- | --- | --- |
| 讨论协作 | 应用1-讨论协作-初始：2节点，管理员及两预设入口 | 应用1-讨论协作-最终：18节点/10Agent，讨论与CSV→JSON成果/Git历史 |
| 资料库 | 应用2-资料库-初始：4节点/1Agent | 应用2-资料库-最终：7节点，真实原文/Wiki/RAG/717版本与历史 |
| NPC小镇 | 应用3-NPC小镇-初始：45节点/7Agent，tick0 | 应用3-NPC小镇-最终：同一网络完成6天/tick30，最后一天增加10项原事件，实际触发9种17次 |

小镇初始保留原场景，第六天事件在五天完成状态追加；完整原始五天统计仍单列。三个应用、成本、截图与断言见../docs/migration/DELIVERY.md。六份项目均经过实际客户端冷打开；第六天另在本机核对了冷导入、7 份 DSH 历史和双击重开。

现版本已清理7个没有入边和组件的旧通信节点；其余节点数据、连接和原生会话历史保留。
