# 移动到此

程序标识：`movement.here`。装在目的地点，携带一个“移动到此”Agent 工具，自动装配依赖“位置资料”。无需 LangGraph。

NPC 与旧地点也应装配“位置资料”，NPC 的初始 location 指向旧地点。NPC 与旧地点之间用 `relation: location` 的双向连接；相邻地点之间用 `relation: road` 的双向道路。新位置边默认使用 location 频道，门槛 1、倍率 1；需要保留本地业务能力时通过 `location_channels` 配置。示例访问强度为 2，频道为 road、location、records；按实际依赖授权。

Agent 沿授权网络取得目的地工具，然后无参数调用。实际移动对象来自核心的 requester_id，不接受伪造的 NPC 编号；允许工具收集器转调而保持发起者身份。先锁 NPC、旧地点、新地点，锁内重查位置、双向道路与位置连接，再更新新连接、访客、位置和 Agent 当地说明，最后删除旧位置边。其他调用与信号等待提交，异常或取消回滚内部节点记录。只修改位置边，不删除其他业务连接；超时后可重新请求。

模块本身不增加权限，过远目标、错误频道和非相邻道路均拒绝；没有文件系统或全图入口。移动后的旧工具在执行时仍重查实际路径，新的工具可沿新地点重新取得。

## 新位置边频道

配置项 `location_channels` 决定移动成功后，NPC 与目的地之间新建双向位置边的频道。它必须是非空、不重复的字符串数组，并包含 location、road 或 movement 中至少一个；默认值为 `["location"]`。旧位置边仍按原完整边精确删除，不会把旧边上的未知频道自动继承到新边。

小镇统一用 location 表达当前位置、road 表达相邻道路，不必在位置边上逐项列出所有业务名。其他应用可按需要配置；新位置频道仍须包含于模块的访问授权。

同时要把这些频道加入移动模块实例的 `access.channels`。新边由核心按移动模块自己的访问授权核验；配置频道超出授权时，整次移动失败，锁内已执行的钩子扣费、访客更新和出边修改全部回滚。该配置只影响新位置边，不改变旧边的删除方式，也不能用来给仅限节点自身的 `self` 频道创建出边。

## 移动前钩子

配置项 `before_hooks` 默认是空数组，保持原有移动用法且不引入额外依赖。每项可填写：

```json
{
  "target": "requester",
  "module": "records.store",
  "operation": "apply",
  "arguments": {"deltas": {"ap": -3}}
}
```

- `target` 只能是 `requester`（发起移动的真实 Agent）、`origin`（锁内重查得到的旧地点）或 `destination`（当前目的地点）；目标节点由框架认证的 `ctx.requester_id` 和真实位置映射，不读取参数里的 actor。
- `module`、`operation` 指向已发布的目标模块公开操作，`arguments` 是 JSON 对象。
- 钩子在 NPC、旧地点、目的地都已锁定，且锁内重查位置、道路和位置边全部通过之后执行；此时尚未修改任何位置数据。数组按顺序逐个 `await`，任一步返回非 `ok` 就抛异常，由整个移动事务回滚之前所有钩子的副作用。
- 成功移动的结果包含 `before_results` 数组，按配置顺序记录每个成功钩子：`{"target": "requester", "module": "records.store", "operation": "apply", "data": {...}}`。其中 `data` 是目标操作返回值的原样 JSON 副本，可携带抵达时的观察文字、概率事件或结算结果，供发起 Agent 直接消费。未配置钩子、或目标就是当前地点而未移动时，`before_results` 仍为空数组。
- 任一步钩子失败时整次移动以错误结束，不返回部分 `before_results`，之前成功钩子的扣费、写入和位置变化都由事务回滚。
- 钩子只调用锁集合内节点的公开操作，不能调用外部工具，也不能自行扩大锁集合。目标模块的频道和路径仍受本实例装配授权约束；需要调用 `records.store` 时，应给移动模块访问授权和相应路径提供记录仓接受的频道；小镇的 location/road 已能承载这些访问。

例如 NPC 的行动力预算可完全放在 Agent 自己的 `records.store` 中：

```json
{
  "initial": {"ap": 10},
  "minimum": {"ap": 0}
}
```

移动模块配置上面的钩子即可扣 3 点；不足时记录仓拒绝，位置边、访客和行动点都保持原样。它只是通用顺序钩子，不为 NPC 或某种预算写死规则，也不强制安装记录仓。

完整正面样板位于 <安装目录>/resources/examples/npc-town/，加载 inspect-network 后用 project 指向它，查看 NPC 移动前后的道路及位置关系。
