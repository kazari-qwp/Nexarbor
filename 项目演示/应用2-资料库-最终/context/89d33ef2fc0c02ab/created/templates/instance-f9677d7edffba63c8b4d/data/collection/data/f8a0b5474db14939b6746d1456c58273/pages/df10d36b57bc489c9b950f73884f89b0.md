## 4. 结构化集合用法

- `quake-events`：字段 event_id（string）、time_utc（string, ISO8601 UTC）、updated_utc、latitude/longitude/depth_km/magnitude（number）、magnitude_type、network、place、review_status。
  - 当前 481 行，时间 2024-09-01T00:49:26.519Z ～ 2024-09-30T21:14:17.212Z，震级 4.5–6.5（minmagnitude=4.5 截断）。
  - 计数、求和、平均用数据库聚合查询；按来源网或震级标度分组统计时注意范围声明。
  - 追加按 `event_id` 去重；实测同一份增量文件重复导入不增加行数（依据 [[de912303b6524cefa452f861e4382996]] 的 UPSERT 语义与导入去重）。
- `reference-catalog`：source_id 为字符串，务必保留前导零；筛选走检索过滤，不要转成整数排序。

## 5. 维护约定

1. 原文页不改写正文；修订只追加新版本记录。补发的重复原件（如 0002）复用既有记录并升版本，不新建重复页。
2. 项目知识页按需求版本分页：v2 为现行页（`quakedesk-project-v2`），v1 保留为历史页并在页首标注「已被 v2 取代」。
3. 整理页必须带 sources 引用；`sources` 只放**依据**，页面之间的替代/跳转关系用双中括号页面链接表达，不要写进 sources——否则互相引用会让 `needs_refresh` 互相触发、永远无法清零。
4. 统计类结论必须写明数据范围（当前 481 行，2024-09-01 至 2024-09-30，震级≥4.5）。
5. 未提供的信息明确写「资料未提供」，不补外部知识；待评估提议必须标注「未验证」，不得写成结论。
