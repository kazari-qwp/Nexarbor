# 观测数据说明与统计口径

本页解释 `earthquake-observations` 集合中的 **481 行**观测记录。数据由两次提交合并：

1. 初始快照 `imports/data/earthquakes-initial.json`（source_id 0014）300 行，此前只覆盖到 2024-09-18。
2. 追加批次 `imports/updates/earthquakes-additional.csv` 181 行（2026-10-20 导入），把覆盖补齐到 2024-09-30。

两次合计正好等于原始查询窗口匹配的 481 行（初始快照的 `held_out_rows` 为 181）。

## 1. 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `event_id` | string | 事件标识，保留原文（如 `us6000nny2`、`us6000nsv4`） |
| `time_utc` | string | 发震时间，ISO8601 UTC 文本，保留毫秒 |
| `updated_utc` | string | 记录最后更新时间，ISO8601 UTC 文本 |
| `latitude` / `longitude` | number | 十进制经纬度 |
| `depth_km` | number | 深度（公里） |
| `magnitude` | number | 震级数值 |
| `magnitude_type` | string | 震级类型，如 `mb`、`mww` |
| `place` | string | 地点描述（英文） |
| `network` | string | 观测来源网代码，如 `us`、`ak` |
| `review_status` | string | 审核状态，如 `reviewed` |

字段名对应 USGS CSV 的 `id / time / updated / latitude / longitude / depth / mag / magType / place / net / status`（0013 仅列列名，未给定义）。

## 2. 覆盖范围

- 时间：**2024-09-01T00:49:26.519Z 至 2024-09-30T21:14:17.212Z**（完整 9 月窗口）。
- 震级：**4.5 至 6.5**（查询条件 `minmagnitude=4.5`）。
- 记录数：**481**，与来源查询窗口匹配行数一致；此前「300/481、只到 09-18」的限制已由追加批次解除。
- 追加批次首条 `us6000nsv4`（2024-09-18T09:01:59.011Z），与初始快照末条（2024-09-18T07:52:28.320Z）时间不重叠，因此不存在跨批次重复事件。

## 3. 追加与去重经过

- 追加方式：按行写入同一 SQLite 集合，字段与既有记录一致，`event_id`、毫秒时间、数值精度、经纬度均保留原文。
- 去重依据：内容相同即复用同一记录（稳定 key 由内容决定），不以「每次导入都新增」的方式累计。
- 重复提交核查：同一份 `earthquakes-additional.csv` 再次导入后，181 行全部映射回既有记录（记录版本递增，如 `us6000nsv4` 记录 2e8dda69e18f472bbd6d1f5cf31291eb 由 v1 → v3），集合计数保持 **481**，未出现重复行。
- 版本递增是重复提交的可见痕迹，不代表数据变化；内容字段未改变。

## 5. 解释注意事项

- `magnitude` 是首选震级，`magnitude_type` 不同不可直接混为同一标度；分类型统计更有意义。
- `updated_utc` 表明记录可能被修订，同一 `event_id` 后续可能更新；按 event_id 做 UPSERT/内容去重，不重复插入。
- 时间以 UTC 文本保存；SQLite 无独立 DATETIME 类型（0008 第 3.2 节），比较与排序依赖 ISO8601 文本格式统一。
- 0012 是接口说明，不是本快照元数据；快照选取条件与行数以 SOURCES.json（记录 ca209cbdbc5c40a8bf2ef184d93416f1）为准。
- 统计结论必须带「481 行 / 2024-09-01 至 2024-09-30 / M≥4.5」口径，不能简写为「9 月全部地震」。
